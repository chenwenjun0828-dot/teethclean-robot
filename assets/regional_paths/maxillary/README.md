# 上颌六区域候选源线

沿用下颌 `outer_left → outer_front → outer_right → inner_right → inner_front → inner_left`
的区域结构和方向，为上颌单独生成源线，不复用下颌三维坐标。

生成方法：按两颌牙弓 XZ 范围转移模板，去掉用于锚点选择的上颌牙龈线 Y 坐标两端各 5% 的支线候选，
将锚点落在上颌已有牙龈线上，再沿上颌网格边求带牙龈距离代价的表面路径，并去除重复顶点回环。
这是新生成的表面候选路径，包含跨原提取片段的网格边路线；不是宣称所有点都来自原提取线边。
参数、锚点、源文件指纹与各区距离记录在 `stitch_report.json`。

`T_camera_scan.txt` 只为兼容现有源数据格式保存本次上颌配准位置，平移单位毫米；
加载时先逆变换还原上颌口扫坐标，后续坐标位置由当前基座变换独立确定。

六区域边界仍需查看确认，`region_boundaries_approved=false`、`robot_execution_allowed=false`。
当前连续曲线导出采用整区两端各裁剪 0.25 mm，不跨区连接。
表面贴合检查不代表机器人执行、接触或配准精度验证。
