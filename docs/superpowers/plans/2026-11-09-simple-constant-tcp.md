# 简化 TCP 匀速轨迹实施计划

设计已由用户确认，直接实施，不再增加审批步骤。

1. 新增固定三次关节路径、C2 弧长反解和起终点平滑的恒速模板；保存和加载完整表达式。
2. 扩展现有 Trajectory 采样、区间边界和速率检查接口，旧 NPZ 格式继续可用。
3. 新计划直接使用姿态搜索的节点，取消生成阶段的递归补点；一次检查固定曲线。
4. 将目标时长直接传入生成器，pipeline 和 planning.execute 对新格式复用时序，不进入旧重定时循环。
5. 更新 CLI、可视化兼容、报告与文档；加入节点通过、C2、恒速、限位及不可行输入测试。
6. 运行必要回归与张口 20 度中区案例，记录实际精度、速度、净距、动力学与计算时间。

不修改用户的无关工作，不复用旧轨迹的验证记录证明新曲线有效。
