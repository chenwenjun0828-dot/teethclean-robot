The extracted-topology three-region branch, left/middle/right aliases, per-tooth
trimming, synthetic bridges and its 90-second example were removed on 2026-11-11.
References to those APIs or parameters in dated documents describe the old code.

Use the root README and the current six-region cleanup record in
`docs/integration/2026-11-11-six-region-cleanup.md` for current behavior.
