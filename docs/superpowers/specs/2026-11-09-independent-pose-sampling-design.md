# 独立增加姿态采样密度

用户要求先增加姿态规划采样点，保持姿态与运动两个模块独立，观察单独加密是否解决问题。

新增 Config.pose_spacing_mm 与 planning/pipeline CLI 的 --pose-spacing-mm。
新计划默认 0.05 mm；几何重建的 spacing_mm 保持 0.25 mm。
姿态模块负责根据该参数采样目标位姿并选择连续 IK，运动模块消费固定输出，
不依据插值、时长或速率审计要求姿态模块继续补点。
历史报告未保存新参数时，按其原 spacing_mm 恢复，保证旧计划校验一致。

与单纯修改共享 spacing_mm 相比，独立参数能保证试验中原几何曲线不变；
与自适应误差反馈相比，固定采样密度不引入模块循环依赖。
本次只增加独立密度参数和调用传递，不改变 IK 算法、关节样条、时序或验证容差。

用相同配准、张口 20 度、55/-20/-140、裁剪 2 mm、离面 2.5 mm 比较采样数、
连续 IK、点间几何误差和 90 秒时序可行性。失败如实保存，不放宽约束。
验证独立参数、非法值前置拒绝、旧配置兼容及几何采样不受影响。
