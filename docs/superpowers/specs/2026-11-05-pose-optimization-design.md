# 牙龈线逐点姿态优化第一版

用户已批准实现碰撞、平滑、切向对齐与小角度偏移的联合优化，并在实现中明确选择：工具 +Y 必须沿编号递增方向，允许先重建参考姿态。

## 输入与坐标

复用 `planning.tooth_frames` 的完整排序导出。每个原始点恰好输出一个姿态，保持点的位置、原牙齿坐标系、新旧索引映射不变。毫米单位口扫坐标用于几何优化；配准后的世界坐标（米）用于离线 IK。真实 gap 或 branch transition 分段独立求解，禁止跨段平滑及扫掠。

参考姿态由同段弧长窗口内的前向切线重建。+Y 是编号递增切线在牙面内的投影，Z 取牙面法线的正/反两种候选，X = Y × Z。用碰撞代价和姿态连续性的动态规划选择朝向；候选间是绕 Y 的 180°刚体旋转，不是镜像，也不改变原牙齿坐标系。方向不按照旧 Y 翻转。优化切向项直接对齐实际前向切线，允许与法线项折中；报告实际夹角。原牙齿姿态与重建参考姿态分别保存。

实现验证发现，始终保持 TCP Z 与牙面外法线同向会在当前数据上显著增加碰撞；TCP Z 本身并未标定为临床工作面的外向法线。因此默认选择 `collision_aware` 参考朝向，保留 `outward_normal` 策略作为对照，明确输出所选正反号。

## 优化

`R[i] = R_reference[i] @ Exp(delta[i])`。每个局部旋转向量分量默认限于 ±20°，向量模长最大可达约 34.64°；不是 Euler 角约束，也不是原牙齿坐标系附近 ±20°。所有容差和权重为可修改工程参数。

加权最小二乘：有限尖端区域以外的工具表面距离不足、尖端穿透、实际姿态的 SO(3) 角增量及角增量变化、工具 Y 与前向切线差异、工具 Z 与所选参考法线差异、零中心姿态偏移。姿态增量用世界/口扫轴表示，弧长归一化，不直接平滑 delta。稀疏雅可比以绝对角度差分计算，避免 float32 网格查询在零角度产生假零梯度。

工具网格复用 MuJoCo 编译后几何与 TCP 标定变换。允许接触区限定为 TCP 周围有限半径（默认 1 mm）的工具表面，而不是整支工具忽略碰撞。保护余量为基础间距 + 配准误差 + 点到 TCP 距离 × 角度不确定性。

## 验证与边界

口扫为开放表面，不使用全局带符号 SDF；采用最近三角形及局部外向法线估算表面侧别。验证增加全部工具顶点、三角形重心、工具边与口扫交点及段内插值姿态检查。插值按 TCP 位移和工具半径乘角位移细分。这些检查不能证明连续体积无碰撞，报告明确 `geometry_certified=false`。

机器人 IK 可选，逐段按采集关节种子求解，检查关节余量、关节跳变和长度归一化 Jacobian 最小奇异值。关节项在本版作为诊断，不加入几何优化目标。机器人连杆、自碰撞、段间转移、物理接触控制及力反馈仍由后续运动规划处理。本版不改变现有碰撞放行规则，也不接入自动执行，固定 `execution_ready=false`。

求解收敛、损失下降和独立约束通过分别报告。参考法线突变、尖端标定不适合或小角度范围不可行时，保留失败候选供查看，不宣称可执行。

## 输出与查看

独立输出目录保存原姿态、切向参考姿态、优化姿态、局部旋转向量、逐点约束、新旧编号、IK 诊断、配置及输入哈希。查看器加载前核对口扫、点坐标、顺序及原坐标系，可切换原牙齿姿态与优化姿态。牙模/相机保持固定，交互角度叠加到所选基准上，保存时明确基准与原牙齿坐标系。

验证覆盖：前向切线的正反符号、缺口独立性、真实 SO(3) 平滑、零附近界限、局部开放表面距离、有限尖端豁免与穿透上限、已知可改善的避碰夹具、不能修复的姿态突变、配准一致性、错模型/错索引拒绝及 IK 失败。真实口扫全量运行并打开真实 Open3D 窗口检查切换/保存/固定视角。
