# Planning 重构：每牙参考平面与中区 15° 工具规划

2026-11-07 更新：下文“实际尖端方向”的旧物理定义由 [轴向 TCP 设计](2026-11-07-shaft-tcp-frame-design.md) 替换。当前 +X 为直杆轴向、+Y 为径向，原点仍在尖端；X=t 的数学约束保持。历史验证须与当时 TCP 配套解读。

最终轴约定以用户最新指令为准：TCP **+X（实际尖端方向）沿牙龈线前进切向**。与每牙参考平面约 15° 为参考，可调整。两个条件并非独立：X=t 后，夹角为 asin(abs(t·n))。实现优先精确切向，记录实测夹角；绕 X 搜索滚转以改变工具主体朝向，不虚构独立 15° 旋转。默认裁剪实测夹角超过 45° 的部分。

此次重构替换原 planning，左右区只实现几何组织，中区实现运动规划和 control 对接。

## 输入与几何

输入为原始口扫毫米网格、外侧牙龈线 OBJ 点/边拓扑、牙齿/牙龈标签、经过来源检查的 CrossTooth 预测、三区配置、世界变换及机器人状态。分割推理属于 perception；planning 消费已有预测。

先对每个真实连续拓扑段进行受偏差约束的三次 B 样条拟合，再将曲线样点按逐牙预测和牙弓单调顺序归属到单牙，组织为左/中/右区。不跨原始缺口插值。每牙用牙龈线附近外侧牙面带的面积加权稳健平面提供固定参考法向，输出平面残差和面支持。

路径切向来自样条解析导数，不以参考平面投影替代真实切向。每点设 x=t，使用该牙固定法向建立正交 Y/Z，枚举绕 X 的滚转分支；按工具主体朝外、有效长度、IK、碰撞和整段一致性筛选。同一连续段保持同一滚转分支，每牙参考平面固定。

## 中区规划

中区默认图左至右，覆盖上下颌各自中间四牙。初版使用可配置非接触离面距离，分别保留原始线和 TCP 路径。每个真实有效段独立规划接近、沿线、撤离；跨牙/缺口经离面过渡，允许停稳调姿。

跨段过渡依次尝试直接关节插值、经初始位姿过渡、有界双向关节空间绕障搜索，所有边使用相同的碰撞采样精度。固定随机种子保证可重复，预算耗尽明确报告未找到路径。允许用配置降低单牙候选覆盖率门槛以检查裁剪短段，但不降低净距、最小连续长度、IK 或运动约束。

使用实际模型、工具 TCP 和关节限位。多分支 IK 经独立 FK 验收，再按关节变化选连续解。姿态条件、工具净距和碰撞检查适用于目标与执行插值。不能仅凭逐点 IK 判定轨迹可执行。

牙齿避碰采用原始三角网格与完整工具网格的 FCL BVH 检查，不能用整颌凸包作牙面。机器人已有碰撞形状参与上下颌净距检查，并检查机器人自碰撞。离散扫掠记录采样分辨率，不把有限分辨率检测表述为无限精度证明。

仅可执行验收通过的连续段。裁剪记录原始样点/牙位/原因，报告长度覆盖率（不是点数比例），缺口保持。无可执行段时输出失败报告而非空成功。初版不自动移动机器人底座。

## 控制契约

Planning 输出自包含的 Trajectory：关节名、时间节点、关节角、速度/加速度限值、阶段、牙号、TCP 目标/实际 FK、配置及场景指纹、验证记录。关节轨迹采用分段五次时间律，连接处速度与加速度为零；控制消费 sample(t) 返回 q/dq/ddq 和阶段，并保留实时接触及跟踪误差检查。允许分段停顿，不宣称全程恒速。

## 模块边界

- geometry.py：三次样条、分割归属、三区、每牙平面。
- poses.py：X 精确切向与滚转姿态分支。
- robot.py：机器人运动学、多初值/分支 IK。
- collision.py：实际几何净距与扫掠检查。
- trajectory.py：连续分支选择辅助、时间参数化、序列化和采样。
- planner.py：中区规划、裁剪、过渡及验收汇总。
- io.py / __main__.py / view.py：输入、命令入口、可视化与报告。

control 和 pipeline 的旧 planning 依赖同步迁移。旧规划专属测试归档后用新行为测试替换，感知测试保留。历史 outputs 保留，不能当作新实现的验证证据。

## 验收

单元测试覆盖样条偏差/缺口、平面、X 精确切向、实测平面夹角与滚转不变性、退化输入、IK/FK、碰撞、分支跳变和轨迹速度/加速度。用真实上下颌输入导出三区曲线与中区结果，报告保留/裁剪长度、最小净距、IK/FK 残差、关节跳变、速度/加速度上限。至少一个真实中区完整段经 control 仿真执行验证，并诚实报告其余失败段。
