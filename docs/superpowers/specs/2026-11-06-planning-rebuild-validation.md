历史记录：2026-11-07 已改为直杆轴向 X / 径向 Y，本文全部轨迹、覆盖率和动力学指标属于修改前的尖端末段方向 TCP。控制加载器已拒绝旧帧，不能将这些结果视为新坐标定义下的验收。

日期：2026-11-06。最终代码以 TCP +X 沿实际牙龈线前进切向为准。此前 Y 切向和可独立调节 X/平面夹角的实验已废弃；控制加载器拒绝该旧约定。

## 已实现

真实连续段三次 B 样条拟合、逐牙预测归属和单牙网格输出、左/中/右三区、每牙固定参考平面、中区滚转候选、多分支连续 IK、原双颌网格和完整工具避碰、进出及绕障过渡、C2 关节时间轨迹、独立 FK 复核、control 动力学执行和 pipeline 适配。旧代码及专属测试已归档备份。

左右区运动尚未实现；后续设计见 planning/README.md。X 与固定平面的夹角由曲线决定，15° 是参考值，不能同时把 X 固定在切向并独立设角。目标姿态精确 X=t，点间关节插值允许的方向误差为 1°、路径误差为 0.1 mm。

## 实际模型验证

使用默认原口扫与外侧牙龈线、同源 CrossTooth 预测、当前仿真安装及开合。两颌非接触离面距离均为 1.5 mm，规划净距门槛 0.15 mm。下颌单牙候选覆盖门槛为 10%，上颌为默认 25%；门槛仅筛选裁剪段，不降低碰撞、IK 或运动约束。最小连续段为 1.5 mm。仍有大量曲线被裁剪，不是完整中区洁治。

## 检查与范围

- `python -m unittest discover -s tests -q`：80 项通过，包括几何、工具轴、IK/FK、分支连续性、时间律、绕障过渡、碰撞与控制契约，以及保留的感知/配准/口腔配置测试。
- `git diff --check` 通过。
- 两颌均独立完整 FK 审计，并实际运行 MuJoCo control；不是仅画目标位姿，也没有逐点写 qpos 伪装动力学执行。
- 本轮真实集成从既有外侧牙龈线与预测输入开始；pipeline 新配准结果的适配通过测试，本轮未重新执行整个 RGB-D 采集到配准流程。

当前模型是 UR5e 结构代理；输出仅用于仿真，未验证真实机器人。分段五次时间律速度/加速度连续，但每个节点停稳，不是匀速扫描。自碰撞每 2 ms 物理步检查，实际网格每 10 ms 检查；规划扫掠最大单关节采样步长 0.004 rad。净距为采样结果，开放口扫不构成闭合实体内部无穿透证明；面罩只用于视觉遮挡。当前没有接触力闭环。

过渡采用固定随机种子的有界双向关节空间搜索。失败表示当前候选/预算未找到有效路径，不证明全局无解；固定滚转分支和候选筛选也不保证覆盖率最优。
