# 逐段牙龈线三次平滑 B 样条

用户已选择上一轮建议的分段三次平滑 B 样条、均匀重采样和局部坐标系方案。本次直接实现该方案，在新牙面规划模块中替换点列高斯平滑与差分切向；原始牙龈线、旧牙齿系及历史结果保留。

每个原始 segment 独立拟合三维三次 B 样条。参数初值为归一化累计弦长；固定两端，最小化数据偏差与二阶导数积分的加权和。通过逐步降低平滑权重满足原始点拟合偏差和稠密曲线对原折线的走廊偏差上限。少于四个不同点的短段明确记录三次自然插值或直线的三次 Bezier 表达；没有足够不同点的段标记失效。

默认在连续 B 样条上构造数值弧长映射，反求等弧长参数，原点保留在拟合牙龈线上。网格投影用于面片定位、法向估计和距离验收，不将离散最近点投影的跳变写回默认曲线。提供 sampling_domain=projected 对照模式；该模式按投影曲线采样，遇投影跳变显式断段，不能宣称保持严格 C2 连续。两种模式均分别记录弧长间距和弦长间距，不混同。

全段实测显示部分扫描牙龈边缘的最近点映射有跳变，故默认保持拟合曲线而以牙面距离作显式约束。曲线不声称零偏差贴在原三角网格上。原始同段轨迹可能跨过由牙齿/牙龈标签分开的多个牙面子网格；这些子网格分别从原始点和旧外法向获得种子与极性，不虚构子网格间邻接，输出有效段在子网格切换处切断。

高曲率源段整体增加等弧长采样数，而不是只在局部插点，以维持每个源段内的均匀性。15° 解析切向步长作为加密目标，最细以 0.05 mm 的默认积分分辨率为界；达到该界仍有较大转角时如实报告，不移动曲线或翻转切向隐藏问题。

切向使用三次 B 样条的解析一阶导数在平滑牙面法向切平面中的投影，b=n×t。法向沿用连通牙面上的面积/距离加权估计；低置信度、投影失败、源曲线走廊超差、切向退化或运动方向不一致均显式失效，禁止跨原始段或失效区插值。

新增全段几何处理开关，逐段选择种子及外向参考，合并输出但不连接断段。保存原始编号、段号、样条系数/节点、参数/源弧长、解析导数、稠密曲线、等弧长取样和统计，查看器显示原线/拟合曲线/采样点及局部系。

验证覆盖噪声平滑、端点、均匀弧长而非均匀参数、解析导数、旋转/平移等变、反向行程、段间隔离、近邻双面、投影异常与短段退化；在现有下颌各连续段上实际运行，记录拟合/投影偏差及坐标系变化，不以机器人运动是否通过作为这次曲线处理的验收标准。
