# 当前 IK 失败点的只读诊断与修复候选

用户要求重点排查失败原因、解决办法及是否应忽略这些点。保留所有当前牙龈点、三区局部系和原始审计状态，先区分位置可达和完整位姿可达。用当前模型的固定 TCP 安装变换换算腕部目标，枚举两种肩部和两种腕部分支，以大臂／小臂长度必要条件检查超伸，再恢复完整肘关节分支并以 MuJoCo FK 交叉验证。

两条离线修复路线：保持完整位姿，沿底座到牙弓中心的水平投影移动底座 50～250 mm；保持布置，绕固定牙齿局部 X/Y/Z 分别采样有限姿态偏角，保持接触点不变。候选不改变场景文件，不写回原曲线、局部系或 IK 状态。

几何模块限定当前 UR5e 结构代理并检查链长、轴向、固定旋转和关节原点；不使用真实 UR7e 的臂长假设。腕部奇异情况应返回不确定而非误判不可达。精确解析目标与原 0.1 mm / 0.1° 容差审计分别表述，保留边界上已满足容差的原成功解。

对能覆盖所有有效点的 200 mm 候选，在独立内存模型中实际改变底座坐标，以完整 mj_forward 逐点验证位置、方向、限位，并保存专属于新安装的关节角。分支优先选择较大 Jacobian 最小奇异值。候选仍不构成碰撞、连续轨迹或动力学通过，不能把独立点解直接用于执行。

自查：输入目标与原数据对应；不以删除失败点提高通过率；位置-only 结果不伪装成原位姿解；模型结构变化拒绝；保存原/候选坐标及逐点结果，验证随机 FK、全部候选和奇异退化。
