# 固定角度下的逐点工作面贴合规划

- 日期：2026-11-13
- 状态：待审核，仅设计，尚未实施
- 需求依据：用户希望大部分沿牙位置的实际工具工作区接触牙齿，并要求细化逐点位置调整方案。
- 当前约束：局部严格 `continuous`；请求角度 `20,-20,10` 度；局部角度搜索关闭；不自动扩大工作区或放宽碰撞规则。
- 实施授权：本轮只要求细化方案，不视为核心实现修改已获批准。

## 1. 问题与目标

当前 TCP 目标是 `p_line(s) + standoff * n_reference(s)`，工作区接触策略只拒绝超容差穿入及禁止部位碰撞，没有要求工作区贴面。

最近实验在固定角度、0.5 mm 接触容差下测试了 13 个统一离面值。0.3 mm 存在非工作区碰撞；1.0 mm 的 430 个沿牙目标姿态及连接边通过，但进场失败，独立退出检查也失败。该 1.0 mm 候选中只有 4 个目标姿态检测到工作区网格相交，不能称为连续接触。

第一版目标是：保留源线、角度定义和工作区分组，逐点调整 TCP 位置，使实际工作面在原线附近贴合真实牙面；随后独立验证连续运动、进出场及仿真执行。

几何贴合只表达网格间隙目标，不代表真实接触力或恒力控制。

## 2. 方案选择与范围

| 方案 | 变量 | 代价与局限 |
| --- | --- | --- |
| 推荐首版：固定角度，逐点法向位置调整 | 每点一个有界位移 | 便于定位位置问题；仍可能因固定角度与非工作区避碰不兼容而无解 |
| 保持 TCP，逐点调整角度 | 每点姿态变量 | 改变用户请求的严格姿态；不作为本轮自动回退 |
| 同时优化位置和角度 | 多维位姿变量 | 搜索较大；应在首版诊断明确后另行设计 |

首版新增一个默认关闭的 `contact_following` 选项，仅支持 `continuous + contact`。已有调用、示例默认参数和旧轨迹仍走原有固定离面逻辑。

不改源线系数、顺序、端点裁剪、牙齿覆盖范围、工作区 1 mm 半径或三顶点划分规则。不删除难点，不通过非接触进退动作绕开沿牙中间段。

旧的固定线节点优化文档仅作为背景。本方案要求检查保存轨迹的区间采样，并允许在失败区间增加求解节点；不继承“只检查节点”的验收范围。

## 3. 几何与姿态的定义

### 3.1 源线、表面参考和接触位置

`p_i = p_line(s_i)` 是原始感知参考，不替换它。Perception 为这些源参数提供派生表面参考：原网格面片索引、最近表面点 `c_i`、可信的局部外法向 `n_i`、局部支持及有效性原因。

最近点和法向应取自同一条连续牙面邻域，利用相邻源参数的面片连通性防止跳到另一层表面。靠近孔洞、折叠、法向冲突或歧义时，标记无法验证，不自动翻转原面片绕序来制造有效结果。

这些派生数据属于新的感知产物，不覆盖原 PreparedRegion 或曲线。保存扫描网格、源线和派生参考的指纹。局部法向可平滑，但必须重新确认方向一致性和邻域来源；它不能替代碰撞端对完整工作面片的验证。

接触目标限定在当前源点附近、同侧牙面的有效局部区域，首版位置半径建议 1 mm。该范围只定义“贴到哪里才算完成清洁接触”；工作区与整个上下颌的原碰撞许可不变。仅碰到对颌或远离源点的其他位置，不计作当前点的贴面成功。

### 3.2 唯一求解变量

在 scan 坐标系中：

```text
p_tcp(s_i) = p_line(s_i) + a_i * n_i
R_i        = 当前 continuous 模式在 s_i 处生成的原始请求旋转
```

`a_i` 是绝对的派生 TCP 法向位移，而非工具表面间隙。`standoff_mm=0.3` 作为首个节点的搜索初值；后续优先使用前一个节点的结果。

第一版保留现有角度参考系。真实网格法向只决定位置调整方向，不悄悄替换姿态参考系。若以后要求角度严格相对真实局部牙面法向，需要单独启用新的姿态策略及对应审计。

允许有界的负 `a_i`，因为源线和弯曲工作面的几何偏置未必要求正 TCP 离面；负值不是穿透许可，仍须通过同一完整几何验证。现有 `standoff_mm` 的非负语义不变，负值只属于显式启用后的新搜索范围。

## 4. 贴面目标与碰撞许可分开

需要同时保留两个测量：

1. `target_distance_mm`：完整工作网格到指定局部目标牙面原始三角片的无符号距离。
2. `working_gap_mm`：现有保守局部有向验证的工作区间隙下界，保留原值及验证状态；不能解释为精确欧氏穿透深度。

建议的贴面目标精度是 0.02 mm，物理目标仍为零间隙。首版按以下条件分类：

| 分类 | 必须满足的条件 |
| --- | --- |
| 贴面目标通过 | `target_distance_mm <= 0.02`，工作区符号验证有效，全部工作区有向间隙下界不低于 -0.02 mm，整机碰撞检查通过 |
| 小范围失去接触 | 目标距离大于 0.02 mm 且不超过 0.1 mm，符号验证有效、全部工作区有向间隙下界不低于 -0.02 mm、整机检查通过，并满足后述覆盖率和连续失联长度约束 |
| 无法验证 | 局部表面、侧别或任何必需查询无效；不计入允许的少量失联 |
| 不合格 | 目标距离超过 0.1 mm、超出工作区策略、禁止部位碰撞或无有效 IK 等 |

0.5 mm 仍是用户配置的工作区最大数值穿入许可。新增贴面目标要求更接近零，不能把 -0.5 mm 的深度作为理想工作点。0.02 mm 是这项新目标的建议精度，与旧碰撞许可是两套有明确用途的量。

FCL 的相交标志和零无符号距离只作测量，不能单独证明正确侧接触。保守间隙验证失败时，不使用最近距离或新的表面参考将其放行。

## 5. 每点的一维候选求解

1. 使用真实工具工作面和非工作面 BVH，沿 `n_i` 改变 TCP 位置，旋转始终取同一个 `R_i`。工具几何检查先于 IK，减少对无效位置的机器人求解。
2. 优先评价上一点的位移、初始位移以及附近的增减值；无法得到候选时再做有界粗搜索。
3. 首版建议绝对位移范围 `[-0.3, 1.2] mm`，粗步长 0.1 mm，局部位移细化到 0.01 mm；范围和预算可配置，失败时不自动扩大。
4. 使用已验证的局部有向间隙寻找零间隙附近的位置。在局部支持保持有效且符号连续的区间内，复用 SciPy 有界求根；对仅相切、不发生符号跨越的情况，用有界距离最小化补充候选。
5. 不假设整段范围内单调，不跨越 `contact_unverifiable` 区间求根，不把 `Check.clearance_m=-1` 当穿透深度。查询无效和无候选分别保存原因。
6. 每点最多保留 3 个分处不同有效位置区间的候选，避免只保留局部最优值而把后续连续连接堵死。到达每点预算时，报告“在当前范围和预算内未找到候选”，不宣称数学无解。
7. 对每个保留候选求现有完整 IK 分支；所有限位、FK、整机及双颌检查继续生效。

固定角度下，若工作面贴牙所需的位置必然引起非工作区碰撞，则输出明确的几何冲突证据。不能自动打开角度搜索、扩大工作区或把工具移到别的牙面来通过。

## 6. 整条路径选择与插值检查

每层 IK 图的节点由“贴面位移候选、对应 IK 解、接触测量”组成，复用现有 lazy whole-path search。

筛选合格候选后，代价偏好更小的贴面误差、位移变化及关节变化。所有差分按相邻源线弧长归一化，避免采样密度改变权重含义。首版建议位移变化率不超过 0.5 mm/mm；关节及姿态连接上限沿用现值。

选出的位移场保存为独立的连续标量参考 `a(s)`，使用现有 SciPy 三次样条能力。对其逐段极值检查位置范围和变化率，不接受插值超调。原 `s` 和 `p_line` 始终保留。

随后复用固定关节样条和 TOPPRA。新的独立 FK 审计同时重建派生 TCP 目标与原姿态，原来的固定 standoff 位置审计仅用于旧模式，不能关闭审计来接受新的位置。

对实际保存的关节插值运动逐段重测目标间隙、全工作区验证、非工作区及整机碰撞。源线参数的空间匹配限制在该段已知参数范围，不允许匹配到其他位置掩盖偏离。

若节点通过但区间内部失联或碰撞，在对应源区间增加节点后重新求解；建议最多 3 轮，最小求解间距 0.025 mm。最终审计还应覆盖每个求解区间内部的独立检查点。仍失败则拒绝，报告范围明确为有限分辨率采样验证，不宣称连续碰撞证明。

## 7. 进出场必须单独通过

沿牙段使用严格角度；进出场允许原有的自由转移运动。只在最后贴近和最初脱离的小段保持清洁端点姿态。

先复用现有 checked straight TCP motion、初始进场和关节空间搜索。若默认法向路径失败，可以在显式启用该新模式时增加有限入口/出口候选：真实局部法向、原参考法向，以及真实法向与正负路径切向的组合方向；测试 0.5、1、2、5 mm 外部点。每个组合必须验证近牙直线段及外部连接，沿途符号不明就拒绝。

仍无法连接时报告 `approach_unverified` 或 `retreat_unverified`，保留具体几何原因和失败位姿。当前已知的 `support_segments_outside_local_band` 等问题可能继续阻断这些候选。

本方案不修改 Heightfield 验证准则，不通过单纯扩大 2 mm 支持带、跳过工作区检查或把正无符号距离当作外侧证明解决进出场。若其成为唯一阻碍，需要另行设计有几何依据的分离状态验证。

沿牙贴合通过、进出场失败时，只输出中间诊断候选，`execution_ready=false`。

## 8. 模块与保存契约

| 所属位置 | 职责 |
| --- | --- |
| `perception/regions/` | 生成源线对应的局部表面参考；保存原面索引、法向、来源和有效性；不依赖 planning |
| `planning/infrastructure/` | 在共享碰撞后端增加工具位姿测量入口，复用同一面片分组、原网格和符号规则，避免复制一套碰撞实现 |
| `planning/pose_search/` | 一维贴面候选及带位置候选的现有 IK 图搜索 |
| `planning/motion_planning/` | 派生位移参考、进出场、关节样条、TOPPRA 及独立贴面审计 |
| `planning/config.py`、CLI、`pipeline` | 显式传参及一致校验；旧配置默认关闭新模式 |
| `control/position/` | 核对新参考及指纹，对实际 FK 状态复测贴面质量；不在执行时临时移动轨迹 |
| `planning/visualization/` | 展示源线、TCP 路径、工作区、实际接触位置和间隙颜色；只消费已有测量 |

拟新增 `surface_contact_reference` 和 `contact_following_reference` 产物。后者保存 `s_i`、表面参考标识、位移场、角度策略、搜索范围及目标精度，并绑定报告和轨迹指纹。原始 `perception_reference.json`、曲线 parts 和几何来源检查继续有效。

执行、重计时、回放和审计必须显式识别新参考版本；缺少或变更贴面参考时拒绝加载为执行就绪轨迹。不能将旧成功报告套到新轨迹上。

建议配置集中表达为：

| 参数或目标 | 第一版建议 |
| --- | --- |
| `contact_following` | 默认 false；本案例显式 true |
| `planning_mode` / `local_angle_search` | continuous / false |
| 请求角度 / 初始位移 | 20,-20,10 度 / 0.3 mm |
| 位移范围 / 粗步长 / 细化精度 | -0.3 至 1.2 mm / 0.1 mm / 0.01 mm |
| 每点工具几何评价预算 / 位移候选上限 | 32 / 3 |
| 贴面精度 / 最大允许失联间隙 | 0.02 mm / 0.1 mm |
| 区域接触覆盖率 / 每牙接触覆盖率 | 至少 95% / 至少 90% |
| 最大连续失联源线长度 | 0.5 mm |
| 工作区半径 / 碰撞容差 / 非工作区间隙 | 1 mm / 0.5 mm / 严格大于 0 mm |

这些是待审核的新模式建议值，不代表实测已达到的精度或覆盖率。

## 9. 实施与验收顺序

1. 完成局部表面参考及工具位姿测量接口，使用真实加载面片和 TCP 变换验证单位、分组及符号，不运行完整规划掩盖单点问题。
2. 在本案例原采样点输出逐点位移可行区间和失败分类，重点检查此前非工作区碰撞与末端支持冲突的位置。保持角度搜索关闭。
3. 完成 IK 图、位移参考和独立审计；先验收沿牙候选，再连接进场和退出。
4. 完成时间分配、保存后重新加载审计及实际 MuJoCo 位置控制仿真，按实际 FK 复测接触质量。
5. 导出沿线间隙曲线、逐牙统计和局部回放，与原 0.3 mm、1.0 mm 固定离面实验对比。

接触覆盖率按原保留源线的弧长加权，不能只数点、按停留时间加权或删除难点后缩小分母。另报相对于裁剪前源线的覆盖，区分源线保留率和接触率。孔洞或歧义位置不能作为允许的少量失联通过。

验收包括：原始源线指纹和保留范围不变；严格角度及原 FK 容差通过；所有被检查状态符号有效、禁止部位无碰撞；贴面覆盖率、每牙覆盖率及连续失联长度均达标；进出场通过；速度、加速度和实际仿真执行通过。只有全部达标，才能同时报告接触目标通过和 `execution_ready=true`。

重点测试：平面上的解析贴合距离、弯曲工具与 TCP 偏置、已知凸凹牙面、最近面跳层、非工作区先碰、固定角度下无候选、多个有效位置区间、插值离面或穿入、窄失败区间、进出场支持失效、接触率弧长权重、来源篡改及旧模式回归。

不得用几何接触率替代恒力或真实接触力验收。未实现力控，本轮结果只限定于已加载网格和仿真轨迹。

## 10. 风险、兼容性与回退

- 固定请求姿态可能与工作区贴面、非工作区避碰无法同时满足；应输出失败位置、接触点和冲突面片，不保证给定角度一定有解。
- 原始开放牙模和保守接触验证可能让部分位置无法验证；改位置不能保证修复验证器的适用范围。
- 位移场过度变化会增加 IK、插值和时序负担；预算和加密轮次必须记录，超预算不隐式放宽目标。
- 默认关闭新选项，旧输入与旧轨迹沿用原规则；新模式产物使用独立版本及新目录，不能覆盖既有结果。
- 实施失败时撤回本次功能改动和新选项，保留已存在的其他开发者修改及实验记录；不回退源资产或混入无关重构。
