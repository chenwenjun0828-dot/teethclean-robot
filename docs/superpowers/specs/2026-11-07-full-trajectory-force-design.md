# 整段牙龈线柔顺力控

在已有中间四牙规划、固定牙模、物理碰撞开启和 1 N 局部力控的基础上，执行来源规划的全部保留段，不重新初始化每颗牙，不跳过失败段。用户给定的核心约束是接触时尽量保持 1 N、最大不超过 3 N；既有一分钟要求作为默认运行预算保留，延长验证必须明确记录。

采用“转移—贴合—沿线—卸力”的状态机。切向和姿态取原规划，沿单牙法线做有质量、阻尼、速度/加速度/行程限制的导纳修正。低力、过力或跟踪滞后时平滑减慢路径时钟，重新贴合后继续。换段先卸力，跨牙时平滑切换法线修正。允许明确指定小角度工具轴向滚转以避免对颌干涉，该调整不改变 15° 入射角，并记录在运行报告中。

沿用原六轴传感器及同状态无接触逆动力学补偿。法向力求解器仅用于独立核验和附加限幅。目标为补偿后接触合力大小 1 N。2 N 进入主动卸力；对候选指令进行独立一步仿真，在指令施加后和积分后均检查 2.5 N 预测阈值、非预期碰撞及无接触转移条件。超限候选不提交到执行状态，已执行样本不回滚。3 N 仍是实际测量硬停止条件。

保留所有源 trace 的对应关系，并分别统计名义弧长进度和满足接触/跟踪条件的弧长。验收分开报告路径完成、3 N 上限、持续接触和一分钟完成。严格通过还要求完整保留段覆盖、洁治时没有小于 0.05 N 的样本、至少 95% 洁治采样在 1 N ±0.2 N 内，以及传感器与独立接触力向量一致。不得只选稳定窗口报告。

对原模型进行整段仿真、保存原始和补偿信号及预测拒绝原因；对状态切换、暂停恢复、法线与滚转变化、缺段拒绝、真实接触预测及不推进已执行状态进行测试。接触模型仍为整颌及工具凸包，没有硬件验证，离散预测不构成真实机器人硬力限保证。
