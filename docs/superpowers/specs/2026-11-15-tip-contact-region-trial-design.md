# 尖端接触区域分级仿真试验

- 状态：已获开发者批准，分级仿真试验完成；三档均存在局部阻断，未生成完整轨迹。
- 问题与目标：开发者明确“工作区”指工具尖端允许接触牙面的范围。当前网页任务固定为非接触模式；区域固定 `35/-20/15` 度、离面 `0.2 mm`、零额外间隙的任务在路径参数 `11.847180706145082 mm` 失败，该点 125 组姿态修正的 1000 个 IK 解均报告工具与下颌网格碰撞。现有报告尚不能区分碰撞发生在尖端还是工具其他部位，也未测出穿透深度。目标是评估现有尖端接触策略能否使该组参数得到完整轨迹。
- 范围：本轮仅通过已有 CLI 与 ContactPolicy 做隔离仿真试验，使用现有真机 session 输入和新输出目录；不修改生产代码、正式配置、工具模型、感知几何、标定或网页默认策略。诊断脚本放仓库外；需保留的日志、参数、诊断与规划报告存入 `outputs/tip_contact_region_trial/<run>/`。网页开放接触参数属于后续方案，不包含在本轮批准范围。

## 设计与选择依据

复用 `planning/config.py`、`planning/infrastructure/contact.py` 和 `planning/infrastructure/collision.py` 的权威实现：显式设置 `motion_mode=contact`，TCP 目标仍离面 `0.2 mm`。工作区为 TCP 球内的完整工具三角面，三个顶点均在球内才获得接触许可，跨界面仍属于非工作区。该半径是工具网格区域的定义，不是牙面接触点的搜索半径，也不移动感知路径。

候选方案与本轮选择：

1. 先启用已有接触模式，工作区半径 `1 mm`、接触容差 `0.05 mm`。这首先检验失败是否仅由整工具禁止接触造成，作为基线。
2. 保持容差 `0.05 mm`，将工作区半径分级设为 `1.5 mm`、`2 mm`。这是本轮允许的范围扩展；比较工作面片变化、碰撞位置及完整规划结果。
3. 增加接触容差会允许更大的负有向间隙，与扩大工作区域不同；当前缺少局部间隙和模型误差依据，本轮不增加。若需要，另提具体数值和证据审核。

工作区采用现有完整三角面局部有向高度场验证；允许的局部有向间隙下限为 `-0.05 mm`，它不是 FCL 穿透深度，也不是力控设定。非工作区间隙仍为 `0 mm` 且实际距离必须严格大于零；传感器、机械臂、自碰撞及双颌检查全部保留。原始网格无法提供可信局部侧别、覆盖或拓扑时仍报告 `contact_unverifiable`。

角度、区域固定姿态模式、既有正负 5 度有界修正、session 相机解释、双颌位置、关节变化阈值、采样间距、速度、轨迹时序及动力学限制沿用原任务，不同时调整。

## 实施步骤

1. 重建同一 session 场景，在原失败点识别工具碰撞面片与 TCP 的相对范围，记录相对 1、1.5、2 mm 球的工作区划分。必要时使用原始面片诊断，不能用 FCL 的相交标记推断穿透深度。
2. 检查各候选半径的实际工作面片是否仍位于尖端；若已包含明显非尖端部位，停止该候选并记录原因，不继续授予许可。
3. 对三个候选逐一做局部诊断；局部可行者运行既有完整规划入口，独立保存参数、输出和日志。不把单点通过认定为整条轨迹通过。
4. 对产生的轨迹核查进出场、整段工具碰撞审计、连续 IK、FK 偏差、覆盖、时序和动力学报告，并以 `load_verified` 复核；报告成功与失败，优先推荐通过完整验证的最小半径。

## 兼容性与风险

本轮不改变任何全局默认值，历史轨迹不重写。接触模式当前对已加载的双颌均检查并可能授予工作区接触许可，不能宣称仅允许指定牙齿接触；更细的牙齿白名单不在本轮范围内。扩大球半径可能把原本禁止的工具面片纳入工作区，因此必须记录面片划分并检查实际部位。局部接触证明与有限间距轨迹采样不构成全局实体内外或连续碰撞检测证明。该 session 保留 `robot_execution_allowed=false`，不连接真机，也不提供接触力控制。

## 验证与验收

- 每轮报告应记录实际 `motion_mode`、半径、容差、非工作区间隙、session 来源和接触面片清单。
- 若局部失败，应区分非工作部位碰撞、工作区负间隙超限、接触不可验证和 IK/连续性失败。
- 只有完整轨迹及其既有审计、动力学与 `load_verified` 均通过，才报告该接触策略下仿真规划通过；若均失败，明确给出阻断原因，不自动扩大半径或容差。
- 无实现改动时不要求重复全仓库单测；运行相关诊断、实际规划、报告复核和 `git diff --check`，不得将 dry-run 当成轨迹通过证据。

## 回退与审核

- 回退方式：停止本轮试验即可；不接入网页或主流程，不覆盖原产物，保留可复核的新输出。
- 审核记录：本会话呈现本方案及具体参数后，开发者于 2026-11-15 明确回复“确认”。批准范围为现有接触策略的 1、1.5、2 mm 半径分级仿真，容差固定 0.05 mm；不包括网页接入、生产默认值修改、更大半径/容差或真机执行。

## 本轮结果与执行说明

结果保存在 `outputs/tip_contact_region_trial/20261115_35_m20_15_offset02/`。参数沿用区域固定 `35/-20/15` 度、离面 `0.2 mm`、姿态采样 `0.05 mm`、沿线/进出场速度 `1/10 mm/s`、关节变化阈值 `0.15 rad`；唯一试验策略为显式接触模式及三档工作区半径，容差固定 `0.05 mm`，非工作区间隙固定 `0 mm`。

| 半径 | 工作面片数 | 原失败点 11.847 mm 的 125 组姿态通过数 | 后续阻断点 29.076 mm 的结果 |
| --- | --- | --- | --- |
| 1 mm | 48 | 107 | 1000 个 IK 解全部拒绝：888 个非工作区碰撞，112 个工作区负间隙超限 |
| 1.5 mm | 48 | 107 | 与 1 mm 相同 |
| 2 mm | 92 | 125 | 1000 个 IK 解全部因工作区负间隙超限拒绝 |

原失败点的交叉面片顶点最远距 TCP 约 `0.79555 mm`，接触发生在尖端。三个半径的工作面片均局限于尖端：2 mm 划分的 TCP 坐标范围约为 x `[-0.918, 0]`、y `[-1.678, 0]`、z `[-0.073, 0.224] mm`，而完整工具距 TCP 最远约 `164.64 mm`。1 与 1.5 mm 的工作面片索引完全一致，扩大数值未增加获得接触许可的完整三角面。

后续阻断点为既有 1853 个姿态样本中的第 1041 层（从零计数），路径参数 `29.076060225031124 mm`、内部牙齿 ID 9；这是沿线稀疏筛查发现的阻断点，不宣称为最早失败点。该点每档均实际检查 125 组修正、8 个 IK 分支共 1000 个解，全部拒绝。2 mm 下额外测量每个 TCP 姿态的一个 IK 代表，保守局部有向间隙为 `[-0.1886564933, -0.1191356751] mm`，最有利修正为 `[5, -5, 5]` 度；仍小于允许下限 `-0.05 mm`。这些数值不是 FCL 穿透深度，不可直接据此选择更大的实机容差。

1 mm 已启动完整 CLI，进入逐位置搜索；独立沿线筛查证明后续采样位置无任何网格候选通过后，主动停止其剩余搜索。其日志及尚未完成的原始报告原样保留，`trial_results.json` 明确记录中止原因，不伪造 CLI 完成或轨迹验收。1.5 与 2 mm 在局部筛查即被阻断，未启动完整 CLI。因此三档均未生成 `trajectory.npz`，未进入轨迹时序、最终轨迹审计或动力学验收，也未运行 `load_verified`。

本轮没有生产代码、配置、网页或依赖变更，没有连接硬件。所有诊断脚本位于系统临时目录中的独立任务目录；保留的运行数据均在本轮 outputs 目录。相对于原步骤，额外做了沿线稀疏筛查，以实际局部不可行证据提前终止无法完成的全量搜索；没有放宽算法、许可范围或验收标准。

产物复核通过：三档参数仅在批准的模式、半径及输出位置上变化；面片划分覆盖完整且工作/非工作集合不交叠；三档失败点均检查 1000 个 IK 候选；场景、机器人模型与口腔设置指纹保持；输出目录无临时源码和轨迹文件。`verification.json` 记录检查结果。`git diff --check` 通过，本轮试验进程均已结束；既有网页服务继续保留。未改实现，因此未重复运行全仓库单测。
