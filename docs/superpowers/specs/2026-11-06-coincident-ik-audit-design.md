# TCP 与三区牙齿局部系重合的逐点 IK 审计

用户要求：每个点暂定机器人末端系与当前牙齿局部系重合，检查是否每点都有逆解。末端采用项目现有 `ur_scaler_tcp`，原点与采样点重合、XYZ 与 `[t,b,n]` 对齐，零悬停、无额外工具姿态补偿。目标 `T_world_tcp=T_world_scan*T_scan_tooth`，读取当前固定场景、保存的牙颌开合及安装位置。

只检查逐点运动学逆解、模型关节上下限和正运动学误差；不启用原悬停碰撞过滤，不使用工具候选角度，不连接关节轨迹，不执行机器人。原有无效局部系不能定义完整目标旋转，另列为 invalid_local_frame，不计入求解失败。

算法复用带真实 qpos/DOF 地址的有界阻尼最小二乘 IK；当前关节边界只留 1e-6 rad 数值余量，不附加旧运动规划的 0.02 rad 工作余量。使用上一成功解、home、初始 Sobol 种子，随后用已求解邻近位姿的不同关节分支补试；未找到点再尝试完整 64 个 Sobol 起点，并从最佳结果进行有界 least_squares 精化。先前成功解只是数值初值，不代表已验证点间连续运动。

搜索时执行 `mj_kinematics` 和 `mj_comPos`，这是官方 API 定义的 Jacobian 所需最小更新；成功后每一个解使用独立 MjData 和完整 `mj_forward` 复核。验收容差为位置 0.1 mm、方向 0.1°，并满足模型关节上下限。

每点保存状态、关节角、尝试数、最佳残差及所用阶段；未找到点保存最佳近似关节角，但不作为解输出。状态使用 not_found，不把有限数值失败称为严格不可达证明。输出按牙位和区域统计、X–Z 分布图及场景/变换/配置来源。原几何与现有规划输出不覆盖。

新增 `planning/ik_frame_audit.py`、`planning/plot_ik_frame_audit.py` 及 4 个审计单测。测试包括含前置自由关节时最小 FK/Jacobian 管线与完整管线一致、目标零偏移构造、成功/未找到/无效目标状态区分，以及无效旋转与配置拒绝。真实结果逐一完整 FK 验证。
