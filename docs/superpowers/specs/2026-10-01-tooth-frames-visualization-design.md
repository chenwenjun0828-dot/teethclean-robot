# 牙齿坐标系可视化改进

用户要求改善可视化清晰度，将代码添加到 `tooth_frames.py` 后面，沿用已有依赖。

增加 Open3D 交互窗口，支持旋转、缩放、原始点编号选择、前后点切换、局部/整牙弓及视角复位。三轴使用加粗实体箭头，原点为深色球，原始牙龈点为青色。增强展示色对比，保持真实几何及深度遮挡。所有几何修改都发生于显示副本，不修改算法坐标系、点或导出矩阵。

替换原 Matplotlib 三角面叠加静态预览，使用隐藏的原生 OpenGL 窗口渲染牙面与箭头，再用 Matplotlib 添加点编号、三轴标签和相同视角的独立三轴示意。右侧示意明确展示可能被牙面遮住的轴。Windows 安装的 Open3D 不支持 EGL OffscreenRenderer，因此不引入 EGL 或其他依赖。

CLI 添加 `--view` 和 `--view-radius-mm`，默认仅保存预览与已有结果，不打开交互窗口。验证实际预览、三轴几何、相机正交性，以及实际 GUI 开关局部视图与切换点。

用户进一步要求选牙齿上的点，新增 `--tooth-surface-demo`。以指定牙龈点为锚，朝牙冠方向的 5 mm 目标处附近选择最近牙齿标签网格顶点，生成独立牙面示例坐标系、预览与选择信息；不修改牙龈点。图中明确标记网格顶点编号，另绘原始牙龈点，避免把示例编号当作牙龈线编号。当前下颌示例为顶点 8848。
