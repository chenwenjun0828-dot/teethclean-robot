# 牙面姿态规划实现约定

实现依据为用户提供的 MuJoCo Dental Orientation Planning 文档及其七个公式图。用户已明确要求按该文档实现；沿用文档方案，不改变已有逐牙坐标系或覆盖既有优化结果。

新增独立入口 planning.dental_orientation 和五个可复用模块：surface_frames、pose_candidates、mujoco_feasibility、trajectory_search、replay_eval。原始网格和历史提取文件保持只读。内部几何统一为米、弧度，矩阵轴为列，四元数导出为 xyzw。

surface_frames 在人工面片掩码或种子限定的连通牙面上进行限幅平滑、投影、等弧长采样及邻域法向估计。首点由种子锁定面片，随后查询限制在前一点附近的面邻接区域。法向绕序符号从种子沿共享边传播，不以翻转真实表面法向掩盖大角度异常。使用 [t,b,n]，b=n×t，失效点保留原因并切断有效段；切向回退有距离限制，禁止跨原段平滑。

pose_candidates 用显式 TCP 工作段轴、工作侧轴、接触点偏置建立功能系 F，按文档 alpha/beta/gamma 公式生成 45 个候选，逐候选补偿 TCP 位置，保存相对姿态与几何复算值。模型几何推断的配置注明尚未进行工作面标定。

mujoco_feasibility 使用私有 MjData、独立 qpos/DOF 地址、多种子阻尼最小二乘、真实关节范围和无模 2π 的去重。悬停阶段所有工具部位禁穿透。原始扫描采样距离及边相交用于工具牙面复核；MuJoCo 距离接口用于显式机器人碰撞对。现有整弓凸包不作为工具牙间空间真值。报告明确标出尚未分牙凸分解的代理和有限采样局限，不标记为接触执行就绪。

trajectory_search 只连接同一有效段相邻层，验证初始位形到预接近点及首点。边按最大 1 度关节步长和笛卡尔分辨率加密，复核 FK 位置、角度、工作侧、禁碰净距。动态规划采用一阶节点和边代价，同时支持固定相对姿态和贪心对照；没有贯通路径就输出首断点，禁止将部分路径宣称整段成功。

replay_eval 对完整路径分配满足关节速度/加速度上限的停止点五次时间律，独立加密运动学回放；可选位置执行器回放并记录实际误差和接触。段间转移与接触力控制不在短段悬停验证范围。可视化显示原网格、面片、t/b/n、失效点和候选工具。

验证包括平面/圆柱、近邻双面隔离、法向绕序、路径反向、段间隔离、退化点、候选工作点不漂移、多个 IK 分支、全局搜索绕开贪心死路、边中间碰撞及实际前牙短段诊断。保留全部硬阈值及失败，不为得到成功结果降低约束。
