# 逐牙分割、单牙曲线与局部坐标系异常剔除

用户已确认逐牙分割、每牙一条三次平滑 B 样条、等弧长采样并剔除大跳变和异常局部系；进一步要求优先使用本机 CrossTooth。本方案落实上述请求。

## 输入与选择

本机 `../CrossTooth_CVPR2025-main` 有公开点特征分支 checkpoint、可用 CUDA 环境及 Windows 推理适配。新推理在独立输出目录运行，不改模型代码和旧结果。模型类别为 1–16，0 为背景，17/18 按原推理入口映射为背景；类别不是已验证的 FDI 牙号。

纯几何牙弓切分容易在后牙和缺口误切；直接逐点 argmax 会在牙间出现类别抖动。选择模型概率与原始线拓扑结合：清除面片小岛，按牙弓顺序约束牙龈点归属，逐牙在真实边图上选最长主弧，保留所有未选点及原因。每个可支持的牙实例只生成一条曲线，不跨真实断口合并碎片。

下颌使用已有旋转对照中 X+90° 的网络输入朝向；原始朝向对照在后牙出现同类跨两颗牙的明显归属问题。上颌使用原始朝向。所有网络输出仍回到原始口扫坐标；保存旋转和来源。这是几何可视核查后的工程选择，不以置信度声称解剖精度。

## 数据流

1. 严格核对预测 summary 的输入 SHA256、完整网格顶点/面顺序与当前口扫；不允许仅按顶点/面数套用标签。
2. 每类保留最大的面邻接连通分量，并按面积与面数排除伪类别；清理不覆盖原始预测。
3. 以现有牙齿/牙龈颜色标签确定牙面支持，读取牙龈点附近模型概率。依据各类别沿牙弓的中心顺序，用动态规划得到单调、每类非空的归属；输出归属置信度与边界，允许人工审查。为修正网络在颈部的局部邻牙误归属，将这些有序牙龈点作为边界锚点：其网格测地 1.2 mm 范围内解除原模型种子，用边界锚点与范围外模型核心共同传播牙位。保留原始标签、清理标签、修正标签与变更面数；不修改网络本身，也不以修正后的曲线贴合自证分割解剖正确。
4. 对每牙原始牙龈边图寻找主弧；分支与独立碎片不补接。每牙导出面编号、主弧点索引与舍弃点。若无足够支持，输出失败原因，不生成虚假曲线。
5. 主弧独立运行现有固定端点三次平滑 B 样条与等弧长采样；法向仅来自该牙关联面区域，保留原有法向支持/可信度检查。
6. 对完整 SO(3) 转角、解析导数转角、法向变化和切向投影退化进行额外检测。默认完整姿态/导数相邻转角阈值 15°；对原始异常边的两个端点同时剔除，避免贪心删除掩盖跳变。小于 3 点或不足 0.5 mm 的剩余有效片段剔除。阈值可配置。
7. 保存全采样点的 valid/reason，以及只含保留点的独立导出；有效段在剔除、牙位或牙面连通分量变化处断开。绝不删除后重新把缺口两侧相连。

## 输出与验收

每牙一条可重建样条，`tooth_id` 对应网络类别并明确非 FDI；全网格逐面标签、逐牙点归属、主弧覆盖率、舍弃点、异常点、剔除前后统计、彩色逐牙预览与 RGB 局部系。低覆盖/大碎片明确标为需复核，不将主弧称为完整环周轮廓。

合成测试覆盖输入坐标不匹配、小岛清理、类别抖动恢复、真实缺口不补接、曲线/牙位一一对应、旋转异常双端剔除及断段不桥接。真实上下颌验证样条可重建、有效矩阵正交且 det=1、保留相邻区间转角在阈值内、拒绝点不出现在 retained 导出。人工查看彩色分割与牙龈曲线。此次仅几何处理，不执行机械臂运动，不声称分割真值准确率。
