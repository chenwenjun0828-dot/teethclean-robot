# 洁治器安装方向旋转 180 度

- 状态：已实施并验证
- 问题与目标：开发者提供末端截图，指出工具安装方向相反，希望在 XML 中绕末端安装轴旋转 180 度。当前 `end_scaler_link` 在 `force_sensor_link` 下的姿态为 `quat="0 0 0 1"`。目标是在关节角和牙颌位姿相同的情况下翻转洁治器安装方向。
- 范围：`assets/simulation/robot/ur7e_with_tool.xml` 的 `end_scaler_link` 安装四元数、必要的资产说明和针对性运动学测试。重新生成 session 几何预览及截图。保留已有工作区修改。
- 设计：采用父坐标系 `force_sensor_link` 的局部 Z 轴作为安装轴，安装点保持 `pos="0 0 0.0405"`。MuJoCo 四元数顺序为 wxyz；将 `end_scaler_link` 的 `quat="0 0 0 1"` 改为 `quat="1 0 0 0"`，相对现状增加绕 Z 轴的 pi rad 旋转。其子级的网格、惯量、TCP、力测量 site 和近似相机一起随父 body 旋转，保留各自局部定义。
- 选择依据：修改安装 body 能让显示、TCP 和碰撞几何使用相同安装关系。只修改 mesh 会导致显示与规划 TCP 不一致；修改第六关节会改变真机采集姿态。若需要传感器与工具整体转动，则应另选 `force_sensor_link` 安装层级，由开发者确认后更新方案。
- 兼容性与风险：所有引用该 XML 的仿真入口都会改变工具位姿，历史轨迹的模型指纹将过期，必须重新规划验证。保持机械臂六关节、法兰、橙色力传感器、牙颌矩阵及归档手眼数据不变；这次仅修正模型安装描述，不代表现实中移动相机或重新标定。模型中的相机为近似定义，不能以画面代替手眼精度验收。
- 实施步骤：获得对此旋转层级及轴的批准；修改 XML 并补安装轴说明；核对 TCP/mesh 子级共同旋转；在新目录生成拍摄关节角下的牙齿与机械臂预览；运行相关运动学和 session 回归。
- 验证与验收：XML 可加载；同一关节角下基座、法兰、传感器及牙颌世界位姿保持不变；工具安装点不变且相对方向变化 pi rad；TCP 和相机位置/方向与共同刚体旋转一致；规划解析 FK 对照 MuJoCo 仍成立；截图由开发者核对方向。没有完整规划与动力学验证时不宣称执行就绪。
- 回退方式：仅恢复本次安装四元数及对应说明/测试，不删除已有资产或输出；保留本次新输出用于对照。
- 审核记录：2026-11-15，开发者在查看左侧原安装与右侧工具安装轴旋转 180 度的对比图及本方案后回复“确认”，批准在 `end_scaler_link` 层级绕传感器局部 Z 轴旋转 180 度、同步更新子级及开展本方案内验证。
