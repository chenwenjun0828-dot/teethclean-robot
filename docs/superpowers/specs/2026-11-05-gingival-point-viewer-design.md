# 仅查看牙龈线点坐标系

用户明确要求查看牙龈线上的点，并授权修改当前查看代码。

`planning.tooth_frames` 命令行及交互窗口统一使用原始牙龈 CSV 的零基点编号。移除命令行牙面顶点选择与牙面示例分支，窗口仅通过点编号及 Previous/Next 切换原始牙龈点，保留旋转、缩放、局部/完整牙弓和重置视角。窗口标题、点标注及预览标题明确指出牙龈线点。已有底层牙面辅助计算 API 保留以兼容程序调用，不再由查看入口使用。

牙面法线、X/Y/Z 定义、口扫/相机/世界转换、CSV 顺序与坐标矩阵导出保持现有约定。原点使用输入牙龈点，不向牙冠偏移或吸附到牙面顶点；索引和几何非法时沿用已有错误检查。文档以牙龈点查看为唯一用户流程。

验证：运行坐标系和姿态规划回归；入口回归检查原始 CSV 点、选中编号和导出坐标一致；使用现有上下颌口扫生成预览并检查原点、轴和标题。

## 固定牙模与查看视角

用户后续要求查看时保持牙齿模型不动。交互窗口默认显示完整牙弓，切换牙龈点只替换原点球、三轴和标签；保留背景网格、牙龈点云及用户当前相机状态，不再逐点调用 setup_camera/look_at。首次打开和手动 Reset view 才设置相机。局部裁剪由勾选 Local gingival region 或 Reset view 显式更新，切换点不会带动裁剪区域。几何计算和静态逐点预览沿用现有逻辑。
