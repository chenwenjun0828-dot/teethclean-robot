# 按牙弓方向重排牙龈点编号

用户要求按当前咬合面截图，从右上后牙沿牙龈线经过前牙，再到左上后牙，编号依次增加。当前口扫中对应从 scan +X 侧后牙，经 scan +Z 前牙，到 scan -X 侧后牙；这不是患者左右的解剖标注。

在查看/导出入口默认启用新编号，0 是右后端，末号位于左后端。先在口扫 X-Z 平面拟合牙弓圆心，以从前方计的径向角对连通分量排序；每个分量从右侧/较早的端点开始，沿真实 OBJ 邻接关系遍历，所有原始点恰好保留一次。分支和环不能总是组成不重复点的单一路径，出现非邻接跳转时划分新的浏览段，并区分原有缺口与分支换段，不补点或补边。图中病例有 18 个原连通分量和 1 个度为 4 的分支点。

坐标、法线、三轴仅作同一置换，不重新计算或平滑。口扫、相机、世界坐标数组和法线距离同步重排。导出新编号 CSV、保持原始连接关系的重编号 OBJ、新旧编号映射 CSV 和排序说明 JSON；冻结的提取和配准源文件不变，哈希校验仍以原始数据为准。

查看器按新编号 Previous/Next，并显示原始编号及缺口/分支提示；保存工具姿态同时写入新编号与原编号。CLI `--point-index` 默认 0，默认 `--point-order arch`；`--point-order original` 可按旧 CSV 索引检查历史问题。几何计算 API 保持原始顺序，默认排序发生在 CLI 载入冻结数据之后。

验证：打乱输入的 U 形拓扑恢复右→前→左顺序，缺口及分支保留全部点、无重复、无新增边；验证坐标系与所有坐标变换同步置换、保存编号可追溯；对当前上下颌导出、渲染标号总览，并实际打开查看器检查新编号切换及固定视角。
