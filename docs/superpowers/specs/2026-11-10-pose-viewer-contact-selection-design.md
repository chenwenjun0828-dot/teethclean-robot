# 姿态查看器：点选牙面接触点

## 目标与范围

在现有 `planning.visualization.pose_angles` 页面中点选牙面位置，将洁治器尖端 TCP 移至该点，方便观察不同牙位的工具姿态。用户已经确认需要修改牙面接触位置，而非修改工具自身的 TCP 标定。

本功能仅改变浏览器中的预览状态，不修改规划输入、已保存轨迹或机器人控制。

## 推荐交互

- 增加“选取接触点”复选开关，默认关闭。开启后可点击或触摸当前显示的牙模表面选点；拖动仍用于旋转视角，不会误选。
- 支持局部牙冠、完整下颌、上下颌三个范围，只拾取牙模，不拾取工具、辅助线或背景。
- 有效选点后立即移动 TCP 和姿态辅助标记，并显示该点在原始口扫坐标中的 X、Y、Z，单位 mm。
- 点击背景时保持当前接触点，并显示未选中牙面的状态。
- 提供“恢复默认接触点”命令，恢复原始接触点和局部参考坐标，不改变三个角度滑块。
- 选点只保留在当前页面会话；刷新后恢复原始接触点，角度沿用既有浏览器记忆。

## 姿态与坐标规则

推荐采用“保持三个角度数值，参考坐标系跟随新牙面”的方式。另一种方案是只平移工具、保持原世界姿态，适合比较同一空间方向，但在不同牙面上三个角度不再表达当地的倾斜关系，因此本次不采用。

- 新接触点来自射线与当前简化展示网格的交点。
- 用交点处插值顶点法线构造局部法线，并朝向点击射线的可见侧；退化时使用面法线。
- 将原始局部参考切线投影到新法线的切平面并归一化；平行退化时使用备用参考轴，构成右手正交坐标系。
- 现有 `toolFrame` 的角度定义与计算保持不变，通过新的接触坐标变换整体移动、旋转工具和辅助图形。
- 坐标显示使用 `models.json` 的 `surfaceFrame` 与 `contactScanMm` 换算回原始口扫坐标。
- 初始点及恢复默认时精确保留当前既有局部参考坐标，不重新估计法线。

这里的网格法线与切线用于局部预览，不等同于规划器使用的整牙拟合平面和路径前进切线；选点不构成 IK、避碰或可执行性验证。

## 模型范围切换

- 下颌与上下颌之间切换时，若接触点所属模型仍显示，则保留该点。
- 隐藏接触点所属模型时恢复默认接触点，例如上颌选点后切换到完整下颌，或完整牙模选点后返回局部牙冠。
- 局部牙冠的选点可在完整下颌或上下颌中继续显示。
- 加载失败时保留原有模型及接触点；快速切换时沿用现有请求顺序保护。

## 实现与验证

- 新增独立的接触点坐标数学模块，负责局部参考基构造、口扫坐标换算和姿态变换；页面负责射线拾取、交互状态和渲染。
- 延续静态服务及离线 Three.js，不新增 Python 或前端运行依赖。
- 为参考基正交性、退化法线处理、坐标换算与默认姿态兼容性增加必要测试。
- 使用浏览器验证三种模型范围的选点、点击背景、拖动不误选、恢复默认、切换范围及角度滑块。
- 检查桌面和手机视口截图、canvas 像素及标签布局，并更新项目 README 和查看器说明。
