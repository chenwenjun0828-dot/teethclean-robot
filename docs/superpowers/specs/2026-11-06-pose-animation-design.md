# 当前洁治器末端姿态动画

用户要求用动画展示当前洁治器末端的移动。读取最新无面罩、连续参考姿态结果 `mandibular_obs_wa_no_mouth_continuous_v1`，验证原牙模、工具及点序来源，不调用运动控制或改写姿态。

输出 H.264 MP4（1600×900、30 fps）及可循环 GIF（960×540、6 fps）。每个原始点的优化矩阵原样播放一帧，不插值或平滑隐藏跳变；19 个源段之间直接切换并提示转移运动未规划，不画跨段连接。首尾短暂停留，按点播放速度不代表物理执行速度。

双视角均固定牙模和相机：左侧展示下颌、牙龈线和 TCP 细节，明确标出上颌隐藏；右侧展示上下颌与完整标定工具。模型用同一 TCP-local 模板逐帧变换，不累积变换误差；RGB 三轴显示末端朝向。叠加当前点/路径段、切向误差、角步长、非尖端相交边数和失败候选说明。

首/中/末画面检查后，为避免完整手柄遮挡，左侧只显示 TCP 周围 14 mm 内的工具网格，并明确标注工具近端隐藏；使用相同相机矩阵投影叠加轨迹和坐标轴。右侧仍保留完整组件。这是显示裁剪，不改碰撞接触区或任何规划矩阵。

Windows Open3D 缺少 EGL，复用现有预览所采用的隐藏原生 OpenGL 窗口；先渲染首/中/末三帧核对视角，再全量渲染。检验摄像机矩阵和牙模顶点固定、跨段不连接、模板变换无漂移、输出帧数/时长、视频与 GIF 解码及首尾画面。
