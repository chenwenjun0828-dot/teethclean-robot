# 可调椭圆口腔开口

用户确认先采用白色。在牙模前方添加白色、略弯曲且有厚度的面罩，中心为真正镂空的椭圆，并有白色圆润口缘。默认净开口宽 45 mm、高 80 mm，可分别调整。

面罩作为 teeth_root 的子体，沿用口扫坐标，默认中心为 (0, 10, 45) mm；+X 为横向，+Y 为纵向，+Z 朝现有全局相机。面罩外尺寸 130 × 150 mm，厚 3 mm，外侧后弯 12 mm。尺寸和位置保存在 config/mouth_opening.json。

采用带孔的三角面网格和 128 段胶囊形口缘。网格三角形不得跨越孔洞。面罩为可见且能遮挡相机的场景几何体；此版本不启用接触碰撞，避免 MuJoCo 将非凸面罩作为封住孔洞的凸包。牙齿现有碰撞设置保留。

独立预览无配准、无 IK、无机器人运动，支持键盘调整宽高、位置、隐藏、复位和显式保存。完整流程默认读取保存参数，也支持一次性的命令行覆盖。直接加载原始 MJCF 时使用内置默认尺寸。

验证覆盖几何拓扑、编译后坐标、尺寸和位置更新、配置存取、真实渲染中的孔洞及 RGB-D 可见牙齿，并运行相关原有测试。宽高不合法或非有限值时拒绝更新；保存采用临时文件替换。

实现顺序：生成静态模型 → 参数及运行时更新 → 完整流程入口 → 独立预览 → 几何和渲染验证 → 使用文档。此目录没有 Git 元数据，设计记录随项目文件保存。
