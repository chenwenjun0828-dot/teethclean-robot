# Planning 工作空间与连续过渡设计

## 目标

当前 planning 在每个有效牙齿片段结束后固定沿牙齿法向撤离 15 mm，再转移到下一片段。某些姿态因为机器人底座位置和固定滚转分支而不可达，导致有效片段过短。此次改进的目标是：

1. 在保持 TCP `+X` 沿牙龈线切向的前提下，搜索更合适的机器人底座平移位置，提升中区 IK 覆盖率。
2. 将 `+X` 与每牙切平面的允许夹角设为 5° 到 30°；15°只作为偏好，不作为硬约束。
3. 在相邻姿态之间选择连续的 IK/滚转路径，限制关节和 TCP 姿态的变化速度。
4. 相邻有效路径优先直接过渡；只有直接过渡发生碰撞或无解时才使用最小必要撤离距离。

## 约束和不变量

- TCP 坐标定义不变：物理洁治器直杆轴向为 +X，径向为 +Y，+Z = +X × +Y。
- +X 仍严格等于牙龈线前进切向，因此切向与切平面的夹角由输入几何决定；底座平移只改善机器人可达性，不改变该几何角度。
- 所有候选姿态仍须通过 IK、关节限位、工具朝向、完整工具/机器人/上下颌 FCL 净距和关节扫掠检查。
- 最终报告保存选中的底座位置；control 必须校验该位置与规划时一致。
- 现有轨迹、TCP 帧标识和场景指纹契约继续有效，旧规划结果不可复用。

## 方案

### 1. 底座位置搜索

`Config` 增加底座搜索参数和可选的固定位置覆盖：

- 搜索中心为当前 `robot_mount` 世界位置；底座姿态保持不变。
- 初始候选在水平面和高度方向进行确定性粗网格搜索，默认范围为水平面 ±100 mm、高度 ±50 mm；最高分区域再以 5 mm 步长细化。
- 每个候选先进行姿态候选和 IK 可达性评估，再对保留轨迹做碰撞检查。评分优先考虑有效中区弧长和覆盖牙齿数量，其次惩罚关节跳变、姿态跳变和最小净距下降。
- 选中的位置写入 `request.json`、`planning_report.json` 和 trajectory 元数据。没有候选通过完整检查时，规划明确失败，不偷偷使用未验证的位置。

底座搜索只改变运行时模型的 `robot_mount` 平移，不修改 XML 几何文件；这样可以复现实验，也不会把临时搜索结果误写入模型资产。

### 2. 姿态范围和连续 IK

配置增加 `min_plane_angle_deg=5`，将默认 `max_plane_angle_deg` 改为 30。15°保留为 `preferred_plane_angle_deg`，用于候选评分。

每个曲线样点枚举允许的滚转候选，并保留所有通过 IK 和碰撞检查的关节解。动态规划在相邻样点之间加入以下转移约束：

- 最大关节步长不超过现有 `joint_step_rad`；
- TCP 相邻姿态变化不超过新的 `max_orientation_step_deg`；
- 代价优先保持关节连续和滚转连续，同时偏好接近 15°的几何片段。

没有可行转移时才切断连续段。切断前允许沿曲线插入中间样点，以区分真正不可达和采样过稀。

### 3. 自适应撤离和过渡

对相邻有效片段依次尝试：

1. 直接从当前片段末端连接到下一片段入口；
2. 若直接连接失败，尝试沿牙齿法向撤离 2、5、10、15 mm，并逐级检查撤离、转移和重新进入路径；
3. 选择首个通过 IK 和完整扫掠碰撞检查的方案。

同一颗牙的相邻片段默认走直接连接；换牙时也先尝试直接连接，只有牙齿网格或机械臂自身碰撞阻止时才撤离。报告记录实际使用的撤离距离和失败原因。

轨迹时间参数仍需满足关节速度/加速度上限。连续 trace 段使用平滑的非零节点速度；撤离、无法贴着过渡的跨牙动作保留可停稳节点。

## 输出和验收

规划报告新增：底座候选数量、选中位置、有效弧长、有效牙齿数、实际平面角度范围、最大相邻姿态变化、实际撤离距离和过渡方法。

验收包括：

- 单元测试覆盖角度范围、候选评分、底座位置应用、连续 IK 转移和自适应撤离；
- 上下颌规划报告中的实际角度均在 5°–30°；
- 独立 trace audit 通过，TCP +X 切向误差和姿态误差在现有阈值内；
- 全轨迹 FCL/MuJoCo 碰撞检查通过；
- control 仿真无传送、无超限，且加载时验证底座位置；
- 与旧结果相比，抬升次数减少或在碰撞约束下保持必要的最小撤离。

## 风险处理

- 若输入几何本身在 5°–30° 之外，底座搜索不能修复该角度，只能明确裁剪对应区间；
- 若所有候选底座都无法提供连续且无碰撞路径，报告保留失败原因和最佳候选诊断；
- 直接跨牙连接即使 IK 可达也必须通过网格扫掠检查，不能仅凭端点距离接受。
