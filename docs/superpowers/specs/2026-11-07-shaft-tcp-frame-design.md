# 洁治器 TCP 改为轴向 X、径向 Y

用户已在完整模型 X–Y 投影图上标出新方向，并要求按该图修改：原点保留实际尖端；+X 沿直杆轴线，从手柄朝工作端；+Y 在弯曲平面内沿径向，朝原投影右下方；+Z=X×Y 为右手系，约指向原图纸内。此约定替换之前“+X 沿弯曲尖端末段切向”的约定。

轴线从实际编译网格的直杆圆形截面拟合，不能使用含相机、支架的整模 PCA，也不能直接假定工具父 body 的 +Z 就是杆轴。使用 40 个共面圆周顶点的截面法向作为轴向，检查平面性、圆周对称性和符号。修改模型 scaler_tcp 的四元数，不移动 TCP 原点、网格、相机或传感器。

Planning 中 X 对齐牙龈线前进切向的数学约束继续使用，新 X 物理含义改为杆轴。报告和控制加载器使用新的 frame_id 及轴约定，历史轨迹不能沿用；已有模型指纹检查同样拒绝旧结果。本次重算整模三轴图及原视角对照图，检查实际模型轴向、径向、右手系、TCP 原点不变和 IK/FK。新轴约定下的完整运动可行性须重新规划验收，旧覆盖率和旧仿真结果只属于历史 TCP。

实施顺序：备份原 XML 和转换矩阵 → 拟合截面并修改 TCP → 更新 planning/control 的帧标识与说明 → 添加几何/原点回归检查 → 重画和检查图片。用户的手绘方向已确定设计，不再增加确认环节。工作区含已有修改，本次不提交其他改动。
