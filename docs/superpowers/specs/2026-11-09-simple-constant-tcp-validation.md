# 固定关节样条与 TCP 匀速时序验证

2026-11-09。实现按已确认设计完成；完整中区案例没有通过新要求，结果如实保留。

## 当前实现

`planning.motion_planning.plan_pose_sequence` 接收世界 TCP 位姿和已有连续 IK 关节角。
省略关节角时先选一次连续 IK。新 pipeline 使用该方法的共同生成器：

1. 保留 n 个输入节点，一次拟合自然三次关节样条。
2. 由实际 FK/Jacobian 计算 TCP 弧长，建立 C2 单调反解；仅细化数值表。
3. 用目标时长和独立的接近时间求巡航速度，两端平滑启停。
4. 检查导出的同一条曲线，保留牙面误差、关节、碰撞和覆盖率约束。
5. 完整计划只做一次 headless 动力学验证；pipeline 复用结果。

新 NPZ 保留 `Q(u(s(t)))` 的完整表示。查看器和控制器调用同一个 `sample`。
旧 NPZ 仍可读，原先细化和重定时辅助函数仅为兼容测试/调用保留。

## 完整中区负例

原输入来自 `outputs/pipeline/check_middle_trim2_duration90_20261109/tracking_source`，
姿态 `55 -20 -140`，张口 20°、裁剪 2 mm、离面 2.5 mm，322 个初始目标。
重新运行当前 `planning.pipeline.run`，沿用原配准、模型、场景、关节上限和几何容差，
目标时长 90 秒。几何重建、可达源筛选和 322 点连续 IK 均通过。
固定匀速时序在进入动力学前拒绝，`execution_ready=false`。

本次总规划墙钟时间 14.671 s，其中几何生成 0.816 s、场景/碰撞建立 1.269 s、
姿态搜索和运动生成 12.566 s。因为明确失败，没有做无意义的 90 秒动力学验证。
这不是与旧成功流程的等价性能比较，不能据此承诺固定加速倍数。

主要异常区间在输入索引 148–156（从 0 开始）：

| 输入区间 | TCP 两端位移 | 最大单关节变化 |
| --- | --- | --- |
| 148 → 149 | 0.003633 mm | 0.05866 rad |
| 150 → 151 | 0.001767 mm | 0.04325 rad |
| 155 → 156 | 0.004186 mm | 0.10841 rad |

这些区间的平移很短，但关节和姿态仍明显变化。固定曲线的 90 秒时序保守界达到
36.353 rad/s 和 222147.86 rad/s²，超过配置的 2.2 rad/s、12 rad/s²。
仅为诊断而密集计算这条时间曲线的导数，实际采样峰值仍达到约
19.63 rad/s、7784.72 rad/s²，说明拒绝不只是保守界过宽造成的。

程序给出的约 11834.8 s 是该固定曲线和启停模板在保守界下的时间伸长估计，
不是任何可选路径的全局最短时间，也不建议仅靠延长到该时间处理本例。
应首先修改问题区域的输入姿态、连续 IK 分支或连接几何。

另外独立诊断发现，此固定关节样条的最大牙面参考位置误差约 1.4714 mm，
旋转误差约 6.5454°，也超过原来的 0.1 mm、1° 容差；延长时间无法修复几何误差。
该诊断轨迹标记为 debug_only_invalid_curve，不允许执行。
若保留全部输入姿态不变，应允许局部减速；若要求严格匀速且紧贴原曲线，
则需进一步调整连接位姿或采用沿笛卡尔曲线连续求 IK 的路径构造方式。
