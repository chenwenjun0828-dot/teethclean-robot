# 恢复交互式洁治器角度查看器

用户明确要求保留并恢复旧交互式三角度滑块。沿用此前已确认的浏览器 Three.js 独立工具形式，
提供 `python -m planning.visualization.pose_angles`，配套离线网页资源和第三方许可证。

当前六区域版本以 `PreparedRegion` 为输入；缺省从附带下颌数据准备区域。
路径参考由共享 `target_at` / `orient_reference` 计算，采用实际注册旋转后的重力，
simple 保持区域固定参考，continuous 使用逐点局部法线。工具顶点从编译后的 MuJoCo 几何变换到实际 TCP。

保留三角度滑块与数字输入、牙面选点及局部/下颌/上下颌范围选择，增加离面距离、
处理后参考线的位置和六区域选择。角度与位置调整保留相机；范围变更或手动适配时重新取景。
选面法线仅用于临时局部姿态，不替代区域规划参考。导出的预览 JSON 不可执行。

验证包括真实工具网格和 FK 的一致性、两种规划模式在真实参考线起中终点的姿态一致性、
非法输入与静态服务，以及 Playwright 实际滑块、区域切换、选面、导出、相机和桌面/手机非空渲染检查。
主 README、模块文档和图片同步更新；不改动规划搜索、控制逻辑或现有用户参数。
