# 前牙区域 [50, 0, 10] 接触判定复核

日期：2026-11-12。

## 结论

按用户指定的牙龈线中段参考点和三个角度重新完成检查。**当前名义姿态不能直接判为接触通过**：924 个节点中，工具非工作段与下颌表面相交的节点有 402 个；工作段相交的节点有 791 个，不能把这些相交整体当成允许的接触。

更关键的是，牙龈线弧长中点相对最近原始牙面片的朝外法线偏移为 **-0.044236 mm**。最近点投影位于该面片内部，局部法线与当前牙位的现有朝外参考法线高度一致。按这一局部侧别定义，固定工作点只改变姿态，无法消除该位置偏差。若使用原草案中 0.01 mm 的示例接触容差，该点已经超出负向容差；本轮没有把这个示例设为实际容差，也没有放宽任何规则。

这是一轮节点几何诊断，未优化姿态、未检查机械臂 IK/碰撞、未执行机器人，也没有把局部侧别结果解释成开放网格的全局实体内外证明。

## 2. 原始面片接触查询

工具共 8150 个三角面：工作段 48 个，跨球边界的混合面片 36 个，其他非工作面片 8066 个。后两组共同组成禁止接触的非工作段，两组节点计数存在重叠，不能直接相加。

| 与下颌查询的工具部位 | 表面相交节点数 / 924 |
| --- | ---: |
| 工作段 | 791 |
| 混合边界面片，属于非工作段 | 311 |
| 其他非工作面片 | 227 |
| 非工作段合并去重 | **402** |
| 传感器 | 0 |

以上为原始三角面 BVH 的表面相交结果，包含可能的接触退化情况，不是有符号穿透深度。工作段的数值接触许可仍需要局部侧别和实际容差，不能由相交数量判断通过。

上颌未发现工具或传感器表面相交。工具非工作段与上颌的最小分离距离约 20.733 mm；传感器与下颌、上颌的最小分离距离分别约 99.979 mm、91.954 mm。

在每个固定节点，对名义姿态及 SO(3) 5° 边界的 26 个方向额外筛查，310 个节点没有找到非工作段与双颌均不相交的候选。这是有限姿态筛查，不是整个姿态可行域的穷举，也不是无解证明。

## 3. 中段参考点的局部侧别复核

最近下颌面片索引为 139529。直接用扫描网格的原始双精度顶点计算：

| 检查 | 结果 |
| --- | --- |
| 朝外面片法线方向的偏移 | **-0.044236274 mm** |
| 正交投影的重心坐标 | [0.234757, 0.746747, 0.018496] |
| 投影是否在面片内部 | 是 |
| 面片是否包含开口/非流形/绕向冲突边 | 否 |
| 面片法线与现有朝外参考法线点积 | 0.996921 |
| 实际工具表面最近顶点到 TCP 距离 | 0.000002434 mm |

TCP 基本位于真实工具表面顶点。即使只考虑该工具顶点，在任意旋转下其相对该局部面片平面的偏移上界仍约为 -0.044234 mm；这说明固定位置下的姿态旋转不能消除该处约 44 微米的负向偏差。

上述判断依赖该处既有朝外法线的约定，不声称开放口扫形成了封闭牙体。原始曲线没有被移动、投影、重新拟合或裁剪。

## 4. 接触判定算例

完成 8 个有明确平面侧别的校准算例，全部通过解析结果核对。其中：

| 已知工具三角片位置 | FCL 表面相交 | FCL 无符号距离 |
| --- | --- | ---: |
| 朝外侧 +0.020 mm | 否 | +0.020 mm |
| 内侧 -0.020 mm | 否 | +0.020 mm |
| 平面上 0 mm | 是 | 不作为分离距离使用 |

因此，**FCL 未相交加上正距离，无法区分分离侧与错误侧**。工具工作段不能整体跳过检查，也不能只用 `distance >= -tolerance` 检查无符号距离。

本轮还保留了 FCL 返回的面片接触深度，但没有把它当作最终的局部有符号间隙或用于容差放行。

## 5. 工作段局部有向距离诊断

每个节点在工作面片的顶点、边及面内部按最多 0.05 mm 的三角网格步长取样，合计 4724 条采样记录。查询最近原始牙面片并记录法线、重心坐标、局部拓扑和与既有牙面法线的一致性。近边/顶点或侧别支持不足的记录保留为不确定，不用于完整接触验收。

- 全部工作段采样的最小局部有向距离约 -0.394655 mm，仅作为采样诊断。
- 在最近点落于面内部、该面局部拓扑正常、法线与既有朝外牙面法线点积至少 0.5 的更严格筛选中，最小值仍约 -0.344409 mm。
- 如果只作 0.01 mm 示例阈值对比，836 个节点存在工作段采样小于 -0.01 mm；其中 717 个节点在上述更严格筛选中仍存在这种负值。
- TCP 目标点自身的局部有向距离范围约为 [-0.109144, +0.182851] mm；729 个节点小于 -0.01 mm，其中 543 个满足上述局部面内部、拓扑和法线筛选。

这些是采样侧别诊断，不是全部工具表面的精确最小有符号间隙，不构成“其余节点已通过”的结论。开放网格无法确认侧别时仍需输出无法验证。

## 6. 接触后端的实施判断

本轮已经证明：仅用现有 FCL 碰撞布尔值或无符号距离，不足以实现草案中的接触容差语义。可靠实现需要同时覆盖原始面片相交、经过验证的局部侧别和接触多处覆盖，符号不可信时应拒绝给出通过结论。

当前参考角可以继续作为姿态优化初值，但不能因此放行整个区域。原线固定时，应先明确输入线相对牙面的负向偏差如何纳入实际接触容差；不能指望三个姿态变量消除 TCP 位置偏差。本轮没有选定或自动扩大容差。
