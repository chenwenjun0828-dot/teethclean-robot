# 简化连续运动：关节样条与 TCP 弧长匀速

状态：用户于 2026-11-09 确认，简化流程已实现并验证；完整 322 点案例的匀速/几何限制见同日验证记录。

## 目标与输入

接收姿态求解得到的有序 TCP 位姿 `T_i`，以及已有连续 IK 分支选择得到的关节角 `q_i`。
生成连续经过这些位姿的运动：清洁主体采用近似恒定的 TCP 平移速度，起终点平滑加减速，接近和回退使用独立的较快时序。

直接复用现有连续 IK 结果，不对这些目标点重新执行降采样、补点和多轮时序重拟合。
若仅提供 TCP 位姿，则先调用现有连续 IK 选择一次；孤立点的可达性不能替代连续解的存在性。

恒速指 TCP 平移速度的大小，不要求关节速度或工具角速度恒定。
输入节点的位姿在既有 IK 容差内满足；点间轨迹由关节样条确定。

## 方法选择

选择 `SciPy CubicSpline` 构造关节路径，再做 TCP 弧长时间参数化。
现有 Python 环境已经使用 SciPy，初版无需引入 ROS、MoveIt 或新的时间最优求解器。

其他方法的取舍：笛卡尔位置与旋转样条需要沿曲线继续求 IK；完整 TOPPRA 接入适合后续需要局部限速时使用。
当前需求优先保持单一巡航速度及简短计算流程。

## 固定关节路径

1. 使用已选定、满足关节限位的连续 `q_i`；不盲目对角度 `unwrap` 后改变已验证的关节范围。
2. 使用 TCP 节点的累计弦长作为初始路径参数 `u_i`。
3. 对六个关节共同构造自然边界三次样条 `Q(u)`，精确通过 `q_i`，保证关节路径关于参数的前两阶导数连续。
4. 样条拟合后固定系数，后续调速保持 `Q(u)` 不变。

相邻完全重复的位姿和关节解可去重。相同位置但姿态不同的输入不符合整段非零平移恒速的假设，初版明确报错并指出节点，不静默删除旋转动作。

三次样条可能在节点之间偏离原始牙面参考曲线，也可能越过关节限位或障碍物。
必须检查实际样条；不能将输入节点的有效性视为整条样条有效。

## TCP 实际弧长

沿 `Q(u)` 做 FK，计算 TCP 的实际弧长 `s(u)`，并建立单调反解 `u(s)`。
应使用实际 FK 弧长，不能将输入点弦长或均匀样条参数直接当作真实行程，否则 TCP 仍会变速。

弧长反解需要保持至少 C2 连续，并与执行时的位置、速度和加速度计算一致。
可使用带端点一、二阶导数的分段五次 Hermite 反解，对单调性及弧长误差做数值检查。
弧长计算和反解所需的内部数值采样不改变输入位姿节点或关节路径。

路径中若存在 TCP 平移速度对参数的导数范数为零的区间或无法正常反解的位置，明确拒绝恒速计划，避免除零或关节速度异常。

## 清洁时序

最终执行表达式为 `q(t) = Q(u(s(t)))`。

清洁段采用对称的加速、巡航、减速模板。
速度加速段使用 `v_c * (3*x^2 - 2*x^3)`，其中 `x` 从 0 到 1；减速段对称。
起终点速度和加速度为零，巡航段速度为 `v_c`，各阶段速度和加速度连续。

若清洁可用时间为 `T`，每端加减速时间为 `tau`，并且 `T >= 2*tau`，则模板行程满足：

`L = v_c * (T - tau)`。

因此可从目标总时长中扣除自由空间段时间，直接求出清洁巡航速度。
起终点加减速时间使用内部默认值，避免增加大量必填参数；只有必要时才开放调试入口。

最终报告清洁巡航段的实际规划 TCP 速度波动，初始验收目标为相对巡航速度不超过 1%。
此数值是数值参数化的验收容差，不代表实际控制器的跟踪精度承诺。

## 检查与失败处理

固定路径后，共用 FK、Jacobian 和碰撞采样结果，进行一次完整路径检查与约束评估。
最终保存并重新加载交付轨迹，确认导出前后使用相同的曲线和时序表达式。
执行前保留既有模型、场景、张口角度、轨迹指纹和高速度动力学验证要求。

检查内容包括：

- 输入位姿通过误差，点间关节限位和完整工具碰撞净距。
- 现有 pipeline 的牙面参考位置、姿态与覆盖约束，保留其原有容差。
- 最终轨迹的关节速度、加速度、工具角速度和 TCP 平移速度。
- 固定轨迹的动力学跟踪与实际净距。

发现不可达、关节分支不连续、几何偏差或碰撞时，输出失败节点或区间，结束本次规划。
不自动进入多轮补点、衰减节点速度或切换旧算法的流程。

对纯速率超限，可计算该固定路径与速度模板需要的统一时间拉伸系数；统一拉伸保持路径及巡航恒速性质。
指定 90 秒但现有约束不允许时，报告该路径和模板所需的时长，不默默放宽限制。
这个时长不是所有可能路径和速度曲线中的全局最优值。

## 工程接入

对新生成的计划使用简化轨迹生成流程，复用现有姿态求解、进场规划、碰撞检查与执行控制。
沿用 `--duration`、清洁速度上限和自由空间速度配置；用户无须逐点提供速度。

采用能完整保存关节样条、弧长反解和速度模板的轨迹表示。
不能在导出时再次用原有按时间拟合的五次关节曲线替代它，否则会重新引入路径变化。
更新加载、可视化与执行的轨迹采样接口，使三者使用同一个表达式。
旧格式已验证轨迹继续可加载回放，不将旧验证记录直接套在新生成的轨迹上。

## 验证

实现后测试：输入节点通过误差、关节与时序的 C2 连续性、起终点停稳、巡航 TCP 速度、弧长反解单调性以及变速不改变关节路径。
测试无连续 IK、重复位置旋转、样条过冲、碰撞和目标时长不可行等失败情况。

用现有张口 20 度、姿态角 `55 -20 -140` 的中区案例进行端到端仿真。
比较规划墙钟时间、运动时间、巡航速度波动、轨迹误差、最小净距与实际动力学结果。
在这些结果出来前，不承诺一定能在给定时长内通过，也不承诺具体的计算加速倍数。
