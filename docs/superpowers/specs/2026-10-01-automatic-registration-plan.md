# 自动配准实现计划

1. 在 automatic.py 实现可校验参数、预处理、FPFH、RANSAC、ICP 和统一方向的返回值。
2. 使用已知刚体变换的部分重叠点云验证全局初始化和取逆方向，必要时检查法向一致性。
3. 接入 register_capture、perceive_gingival_line、run_pipeline 和配置中的方法开关。
4. 添加独立点云 CLI、保存格式和开发说明，更新项目结构及运行示例。
5. 添加有实际几何验证的算法测试、自动流程及异常停止测试，运行完整回归。
6. 在已有牙齿数据上保存自动配准结果与独立评价，报告结果及适用限制。

本项目目录没有 Git 元数据；设计与计划保存为文件。
