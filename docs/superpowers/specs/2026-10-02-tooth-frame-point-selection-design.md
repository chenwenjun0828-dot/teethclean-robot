# 牙面点序号选择

用户要求自行选择点查看，允许使用指定点序号，且保留既有无额外依赖约束。

普通模式保留 `--point-index` 对应原始牙龈 CSV 的零基索引；新增 `--vertex-index` 对应口扫网格原始顶点的零基索引。不得把经过牙齿标签过滤后的紧凑数组位置当作原始顶点号。明确指定牙面点与自动牙面示例参数互斥。

通过 `ToothSurfacePointSelector` 缓存口扫、牙齿标签与牙弓外向绕序；输入顶点号后，以该顶点实际位置计算局部法线及坐标系。牙面窗口的数字框、Previous、Next 切换牙齿区域顶点，原点标签同步显示真实网格编号。非法编号或牙龈顶点提示错误，保留当前成功视图。

原始点、配准和算法矩阵不修改。命令行指定的点保存为已有牙面示例输出文件；窗口后续切换仅用于查看。验证编号一致性、牙龈/越界拒绝、实际顶点 CLI 导出，以及真实窗口中有效/无效点切换。
