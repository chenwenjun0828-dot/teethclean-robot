本次主要更新六区域分段路径功能和人工配准界面。以下路径均相对于项目根目录。

## 1. 六区域分段路径

### 新增功能

- 支持下颌六区域路径：外侧左后牙、外侧前牙、外侧右后牙、内侧右后牙、内侧前牙、内侧左后牙，共 688 个源路径点。
- 保留各区域的点序和方向，不跨区域直接连接路径端点。
- 支持 MuJoCo 静态预览，按 `0` 显示全部，按 `1`～`6` 查看对应区域。
- 支持仿真 RGB-D 采集、FPFH＋RANSAC＋ICP 自动配准，再将六段路径转换到本次仿真世界坐标。
- 支持按区域进行 TCP 姿态计算、逆运动学、轨迹预检与顺序执行；每段包含接近、进入、沿线、撤离，全部所选区域预检通过后才执行。
- 工作姿态模式增加牙缝跨越、可达性筛查、非工作部分避碰和局部时序处理。已有六段完成记录属于 `geometry` 几何运动演示，完整六段接触运动尚未验证，不包含力闭环。

### 运动规划的输入和输出

源路径文件：

```text
assets/regional_paths/mandibular/
├── regional_chain_candidates_camera_mm.csv  # 六段位置点，旧相机坐标，毫米
├── T_camera_scan.txt                       # 将源路径还原到口扫坐标的变换
└── metadata.json                           # 模型信息、区域顺序和输入校验信息
```

读取和规划链路：

```text
源路径 CSV
  → load_regional_paths：恢复口扫坐标路径
  → 本次仿真自动配准：转换到世界坐标，单位米
  → tooth_aligned_targets：结合口扫牙面几何生成 TCP 位置与姿态
  → 根据运行模式处理工作姿态或姿态筛选
  → plan_region(model, scratch, filtered, speed_mm_s)
  → plan_tooth_aligned_tracking：IK、轨迹规划和预检
  → run_path_tracking：执行规划轨迹
```

**机械臂规划器的直接输入是 `filtered` 中有序的 TCP 目标位姿，每点一个 `4×4` 的 `T_world_tcp`；同时传入机器人模型、当前关节状态和速度参数。源 CSV 仅包含 XYZ，不能直接作为完整机械臂运动指令。**

每次运行输出到 `outputs/regional_tracking/<本次目录>/`：

| 文件 | 含义 |
| --- | --- |
| `regional_report.json` | 整体状态、各区域预检与执行状态 |
| `preflight/<区域>/source_gingival_line_world_m.csv` | 本次配准后的源路径 XYZ，世界坐标、米 |
| `preflight/<区域>/requested_T_world_tcp.npy` | 姿态筛选前的 TCP 目标位姿 |
| `preflight/<区域>/T_world_tcp.npy` | 实际送入规划器的 TCP 目标位姿，形状为 `N×4×4`，平移单位米 |
| `preflight/<区域>/joint_waypoints_rad.csv` | 规划得到的六关节路点，单位弧度 |
| `tracking/<区域>/` | 进入执行阶段后生成的跟踪数据和报告 |

以上文件是运行时导出的记录；程序通过内存对象传入规划器，不会重新读取导出的位姿文件。静态预览生成的 `regional_paths_world_m.csv` 也不是当前运动入口直接读取的文件。

### 运行入口

在 Linux 项目根目录、已安装项目依赖的 Python 环境中运行：

```bash
# 六段路径预览，使用本次仿真自动配准
OMP_NUM_THREADS=1 .venv/bin/python -m pipeline.path_viewer --placement automatic

# 六段只做规划预检
OMP_NUM_THREADS=1 .venv/bin/python -m pipeline.regional_run \
  --plan-only --headless --robot-offset-mm -160 -120 100

# 六段仿真几何运动演示
OMP_NUM_THREADS=1 .venv/bin/python -m pipeline.regional_run \
  --robot-offset-mm -160 -120 100 --playback-speed 10
```

`--robot-offset-mm` 是本次仿真使用的基座位置调整；`--playback-speed` 仅调整展示等待，不提高物理关节速度限制。环境安装见 [LOCAL_SETUP.md](../LOCAL_SETUP.md)，详细分段参数见 [REGIONAL_PATHS.md](REGIONAL_PATHS.md)。

## 2. 人工配准新界面

### 新增功能

- 同一窗口左右显示：左侧相机点云，右侧口扫模型。
- 按同名点逐对选择，显示编号和当前配对状态，默认至少六对。
- 支持撤销最后一次选择、清空配对、恢复视角、完成和取消。
- 未达到最少完整配对数或存在未配对的左点时不能完成。
- 主流程人工配准模式和真实点云实验入口复用同一套窗口。

### 启动与操作

```bash
OMP_NUM_THREADS=1 .venv/bin/python -m pipeline.run \
  --jaw mandibular --registration-method manual
```

| 操作 | 方法 |
| --- | --- |
| 选择一对 | 按住 `Shift`，左键先选左侧相机点，再选右侧口扫同名点 |
| 撤销 | `Undo`、`Backspace` 或 `Shift＋右键`；有待配对左点时撤销该点，否则撤销最后一对 |
| 清空 | `Clear pairs` |
| 恢复视角 | `Reset views`，保留已选标记 |
| 完成 | `Finish & Register`；也可按 `Q` 或 `Enter` |
| 取消 | `Cancel` 或 `Esc` |

完成后主流程继续配准、规划和仿真执行。窗口需要桌面显示；`--headless` 不会跳过人工选点。

主流程配准结果位于 `outputs/pipeline/<本次目录>/registration/`，其中 `landmark_correspondences.json` 保存配对坐标、索引和初始残差。该文件在配准及输出阶段写入，若此前报错可能尚未生成。完整界面说明见 [registration/README.md](../perception/registration/README.md#人工配准窗口与框架接入)。
