# 卡点诊断记录：接触资产静态几何门槛

诊断日期：2026-11-13。所有结论均由 `outputs/control/force/_exp_*.py` 的实测数据支撑。

> 本文档在 2026-11-13 晚间经第二轮实测修订。早期版本中的若干结论
> （"网格绕序不一致"、"失败率 38%"、"工具薄壁被穿透"）被后续实验证伪，
> 下面记录的是**经复测确认**的版本。

## 结论摘要

`assets/contact/outer_front_local/` 未通过静态门槛，卡在**校验器
（`union_check`）的判据**与**几何实现的接缝台阶**两处，二者独立可加：

1. **校验器判据缺陷**（主因）：
   - 参考面用整扫描而非 band 限定面；
   - 用原始面法向把规划接近方向**翻转**，导致射线起点落进实体内部；
   - 把"首次命中面不是 `working`"一律判为几何失败，但接缝侧壁/底面在几何上
     位于工作面**内侧**，射线沿工作面法向接近时先撞到它们。
2. **几何实现**：接缝台阶深度正比于挤出厚度。厚度 0.5 mm 时台阶可达 0.37 mm，
   远超 0.1 mm 门槛。

修法：**厚度降到门槛以下 + 校验器改用带符号的命中点判据 + 起点自由空间校验**。

## 经复测确认的事实

### 事实 1：扫描网格绕序**完全一致**，原始面法向就是外法向

先前"绕序不一致"的结论来自我自己的一个错误测试（把"同向遍历"当成冲突）。
正确测试（每条无向边的两个面是否反向遍历）：

```
全局:  冲突遍历 0 / 354,605 条无向边
各牙:  冲突遍历 0， 带符号体积全部为正（+17.7 .. +408.3 mm^3）
```

因此 `convex_patch` 的挤出方向（`top - thickness * normal`）本来就是**向内**的，
**不需要**任何法向翻转或符号修正。

### 事实 2：现行实现（每分片凸包 + 自身法向挤出 t=0.5）的真实失败率是 **0.56%**

用修正后的校验器（band 参考面 / 外法向接近 / 起点自由空间校验 /
按**命中点**判 0.1 mm）重测：

```
current t=0.50   POINT fail 287/51698 = 0.56%
current t=0.20   0.30%
current t=0.10   0.10%
current t=0.05   0.00%
```

注：`connected_groups` 已把 band 切成很小���分片（大小直方图：
1 面 2998 个、2 面 3322 个、3 面 4429 个、4+ 2547 个），所以接缝台阶很小。
先前测到的 38% 来自一个**错误基线**（每三角形各自按自身法向挤出），
不是现行实现。

### 事实 3：残余失败全部是"射线先撞到 band 之外的牙面"

```
FAIL bottom | ray crossed a non-band triangle first = True    226
FAIL side   | ray crossed a non-band triangle first = True    200
FAIL side   | ray crossed a non-band triangle first = False    32
FAIL bottom | ray crossed a non-band triangle first = False    28
```

即：**斜向接近时射线先擦到工作带之外的牙面**（band 半径 8.8 mm 的边缘），
band 参考面看不到这次命中，射线继续深入牙体，撞到接触层的内部侧壁/底面。

正确处理：
- 参考面用**完整扫描**；
- 若原始扫描的首命中面**不属于 band**，该样本判为**超出工作带**，
  单独计数，不算几何失败。

### 事实 4：接缝台阶深度正比于挤出厚度

平滑外法向场 + 逐三角形棱柱（帽面 = 原始三角形，零凸出）：

```
t=0.50   首命中点 >0.1mm: 3.67%
t=0.30                        2.39%
t=0.20                        1.57%
t=0.10                        0.00%
t=0.05                        0.00%
```

用每分片凸包 + 平滑场，数值几乎相同（0.065% @ t=0.10）。

**结论：厚度必须 ≤0.1 mm**（取 0.05 留足余量），
或者必须消除接缝台阶本身。逐三角形棱柱的帽面就是原始三角形，
理论上台阶为 0，实测残余来自凸包在非共面三角形上的弦误差。

### 事实 5：工具尖端是薄壳，固定 0.5 mm 挤出必然穿壁

工具 STL 的绕序**不一致**（仅 84.7% 面外法向朝外），且是薄壳：

```
壁厚 p10 0.0865 mm   p25 0.1529 mm   中位 0.1983 mm
```

以"相邻反法向面之间的距离"度量局部壁厚后，按壁厚自适应挤出：

```
工具 固定 t=0.5            FAIL 22.60%
工具 按实际壁厚（min(0.5, 0.4*壁厚)）   FAIL  0.55%
```

**这一条证实了原计划"工具尖端按实际壁厚处理"的判断**，且效果显著。

### 事实 6：MuJoCo 对 mesh 碰撞几何取凸包

用带方槽的封闭网格实测：球停在 z=0.5796（凸包顶面 0.58），而不是凹槽底部 0.33。
因此接触体必须是小的凸体，或改用 `libsdf_plugin.so`。

### 事实 7：射线起点穿实体是普遍现象，不是边缘情况

以修正后的校验器（完整扫描参考 + 起点自由空间校验）统计：

```
牙齿:  invalid_origin_inside_solid  108,020 / 682,466 = 15.8%
工具:  invalid_origin_inside_solid    1,584 /   4,075 = 38.9%
```

原实现用 `采样点 + direction*0.75`，凹面处起点会落在实体内。
这必须**单独计数**，不能记为几何失败——它衡量的是采样方式，不是资产质量。

## 最终修复方案

| 层 | 改动 | 依据 |
| --- | --- | --- |
| 校验器 | 参考面=完整扫描；接近方向=外法向且**不翻转**；起点外移 R=3mm 并校验自由空间；按**命中点**判 0.1mm；band 外的首命中记为 out-of-band；起点在实体内记为 invalid | 事实 2/3/7 |
| 几何 | 厚度 0.5 → **0.05 mm**；接缝台阶降到门槛下 | 事实 4 |
| 工具 | 厚度按**实际壁厚**自适应（min(0.5, 0.4×壁厚)），固定 0.5mm 一律拒绝 | 事实 5 |

门槛本身**不放宽**：0.1 mm 首次接触门槛与 0.05 mm 面片距离保持为硬约束。
