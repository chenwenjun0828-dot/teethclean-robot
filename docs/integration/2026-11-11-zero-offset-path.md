再次独立回放全部 1,505 个已记录实际关节状态，未发现碰撞。

这次短段实验显式使用 **0.005 mm** 检查余量，不能称为满足原默认的 0.15 mm 余量。
零偏移感知曲线靠近牙面，原 0.15 mm 离面余量会排除大多数点；降低检查余量
不等于关闭网格相交检查。默认项目参数没有被修改。

## 结果的适用范围

这是从感知输出中明确选择并另存的验证区间，planning 未再裁剪、重构或连接曲线。
所选区间与父曲线的最大位置差约 1.21e-14 mm，来源和覆盖比例保存在
`perception/selection.json`。本实验对选定牙实例的最低覆盖阈值使用 0.01，
用于验证短段可行性，不能代表完整牙齿或完整区域的清洁覆盖。

这里的 9 是 CrossTooth 实例编号，不能当作标准牙位编号。
姿态角仅是此次几何避碰搜索的结果，未验收工作尖相对牙面的临床使用角度。

offset = 0 是相对于已有感知曲线的法向偏移为零；拟合曲线不严格等于扫描三角面。
记录的实际沿线工具网格间隙为 0.057921–0.182840 mm，所以不能据此宣称已经
实现整个区间的实际牙面接触。本次也没有运行恒力控制。
动力学沿用现有位置规划验证方式：牙颌原始 FCL 网格替代整颌凸包进行避碰，
不使用此前产生提前接触力的整颌凸包来证明真实牙面接触。

以上均为有限分辨率仿真检查，不是连续碰撞检测证明。
现有角度网格搜索未找到完整区域的零偏移路径，不能将有限搜索失败解释成数学无解。

## 查看结果

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m planning.view `
  --plan outputs/contact_1111/zero_search/front_zero_verified_attempt/planning `
  --speed 1
```

主要文件：

- `planning/trajectory.npz`：通过验证的时序关节轨迹。
- `planning/zero_offset_pose_and_joint_path.csv`：可读 TCP 目标位置和关节角。
- `planning/planning_report.json`、`execution_report.json`：规划与动力学报告。
- `planning/independent_actual_replay.json`：独立实际关节状态回放检查。
- `perception/selection.json`：原感知曲线的所选区间与覆盖比例。

完整复现命令见结果目录 `README.md`。
早期 `tool_screen` 和 `tool_screen_30um` 初筛曾混用两个坐标变换，已作废；
只有 `tool_screen_consistent` 初筛及最终完整规划、动力学和回放检查支持上述结果。
